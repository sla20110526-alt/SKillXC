# SKillXC

本仓库用于设计和实现“抽屉式 AI 影视生产 Skill 系统”。当前第一版只覆盖已有剧本或生产内容明确的真人写实项目，使用 GPT Image 2 制作图片资产、Seedance 2.0 生成视频，终点为正式镜头 Prompt 与生成可用镜头。

## Skill 结构

- 7 个生产控制 Skill：类别锁定、事实索引、资产需求、路由交接、审批登记、版本记录、连续性与就绪。
- 17 个创作生产 Skill：风格、资产、剧作、导演、表演、摄影、灯光、镜头、剪辑、声音与 Prompt 装配。
- 1 个独立影视大师 Profile 资料库。
- 1 个按需视频 QC Skill。

全部 Skill 位于 [`skills/`](skills/)。项目数据默认采用 Markdown 卡片、CSV 表格与 JSON Schema 检查。

## 当前硬规则

- 只有用户明确说“登记这张”“确认登记”等，结果才进入正式资产登记表和可调用资产表。
- 失败结果不登记；失败原因只在用户明确要求时记录。
- 人物以一张五视图总览卡作为 Seedance 2.0 的单人物参考。
- 通用创作 Skill 使用前先请用户确认；大师 Profile 到对应阶段再询问是否调取。

当前状态：v0.1 首轮结构和模板已完成，所有 Skill 已通过格式校验；后续将在真实项目中验证和迭代。
