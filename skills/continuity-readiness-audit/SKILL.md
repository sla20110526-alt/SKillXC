# 连续性与就绪审计

## 只认正式资产与有效控制卡

先读取项目数据绑定卡。资产只读取项目 ID 一致的正式资产登记表与可调用资产表；表演只读取绑定项目 `creative-control/acting/` 中 `已生效 + 当前有效=是` 的母档版本，以及任务索引可追溯的场戏表演卡；声音身份只读取 `creative-control/sound/` 中 `已生效 + 当前有效=是` 的身份卡版本和任务索引可追溯的场戏声音卡。候选/失败资产、待确认/已替代控制卡、临时声音、其他项目数据均不能冒充正式声音资产。

## 两级检查

### 场次就绪

- 当前剧本版本和范围有效
- 人物基础脸、五视图卡、服装和状态版本正确
- 场景母图、所需视图、空间锚点和光源版本正确
- 道具、生物和 VFX 满足场次需求
- 有台词、独白或持续画外发声的角色已明确声音身份卡和正式声音资产，或已标出需要用户选择的临时声音路线；没有发声角色时明确写“本场无需独立声音资产”

### 生成单元就绪

- 分镜组 ID/版本、镜头 ID/版本集合和生成单元 ID 可唯一对应
- 重要角色引用当前有效的表演母档版本，并且本场表演卡版本与分镜一致；没有适用重要角色或简单角色跳过时写明理由
- 当前镜头实际引用名可用
- 参考负载未超过 Seedance 2.0 当前工作配置
- 人物、场景、道具之间没有版本冲突
- 开始/结束状态、左右手、银幕方向、视线和动作接点可承接
- 对白、声音身份卡版本、声音来源、环境声和禁用声音已明确

## 声音来源门

- 逐个核对当前生成单元的发声角色，不能用“本场有声音”笼统通过。
- 正式声音资产必须有 `声音资产ID@版本`、平台引用名、调用方式与限制；当前工作配置不支持直接音频参考时，不能把它写成已上传。
- 用户明确选择 Seedance 临时镜头内声音时，本单元可记 `有条件继续`，并保存确认原文和跨镜一致性风险；不能把临时声音写入正式资产切片。
- 需要发声但既没有正式声音资产也没有用户临时声音决定时，结论必须为 `暂停`，返回 `sound-voice-direction`；审计 Skill 不替用户选择。
- 只有非发声场次可以在没有声音资产的情况下直接通过声音门。
- 就绪表中的声音身份、正式资产和临时决定三列都必须显式填写；不适用时写“不适用”，不得留空掩盖缺口。

## 变更传播

正式父资产更新时，列出所有派生变体、场景视图、分镜和 Prompt 的复核范围。不要自动认定子资产继续有效。

## 输出

- `就绪审计卡.md`
- `场次资产就绪表.csv`
- `生成单元就绪表.csv`（进入正式 Prompt 前）
- 审计结论：`可继续 / 有条件继续 / 暂停`
- 缺口列表：责任 Skill、所需输入、返回节点

使用 `assets/就绪审计卡模板.md`、两张 CSV 模板、`scene-readiness.schema.json` 和 `generation-readiness.schema.json`，按 [项目数据三层契约](../production-router-handoff/references/project-data-contract.md) 生成检查报告。Schema 通过不替代正式资产、版本依赖、参考负载与连续性业务复核。

不得用最接近的旧资产代替缺失资产，也不得在 Prompt 中掩盖上游缺口。
