# 剧作与场戏节拍

## 进入前

列出可用编剧/剧作 Profile，询问用户是否调取。无明确选择时只用通用方法。Profile 只影响分析方法，不得改写原剧本事实。

## 锁定

- 原台词逐字保留，除非用户明确授权修改。
- 事件顺序、人物出入场和因果不改变，除非用户明确授权。
- 区分剧本事实、表演解释和镜头建议。

## 分析

1. 写明本场进入状态、离开状态和不可缺失的事件。
2. 明确每个主要人物此刻想从谁那里得到什么。
3. 明确障碍、失败代价和人物当前掌握的信息。
4. 将场戏分为通常2—6个节拍；每个节拍必须发生策略、信息、权力或关系变化。
5. 标注说出口的内容、潜台词和听者已经感知到什么。
6. 识别沉默、延迟反应、动作中断和声音先行等关键节点。
7. 标明观众信息：已知、误以为、此刻揭示、继续隐藏。

## 输出场戏节拍卡

`节拍编号 / 触发事件 / 人物目标 / 策略 / 可见行为 / 潜台词 / 信息变化 / 权力变化 / 进入状态 / 离开状态 / 原台词范围`

只交给 `directing-blocking` 和 `acting-direction`。不要提前决定焦段、机位或运镜。
