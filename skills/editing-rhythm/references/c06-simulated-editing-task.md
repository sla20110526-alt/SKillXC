# C06 模拟剪辑节奏任务

本文件只验证轻量生产回显、逐镜关系、生成单元身份和写回边界，不建立具体项目数据，也不宣称通过真实剪辑创作验证。

## 模拟输入

- `SBG-DEMO-012@v001`：三个镜头。镜头A中主任说“坐”；镜头B中林舟不坐、绕过椅子并把信封放上桌；镜头C中主任先看信封再看林舟。
- `DBD/DBC`：林舟移动的触发是命令结束，动作完成点是信封离手；主任保持位置，第一次视线改变发生在信封落桌后。
- 场戏表演卡：林舟在命令后保留短停顿再移动；主任必须完成“看信封—判断—抬眼”的反应链。
- 场戏摄影约束：镜头B的跟随运动必须完整停住，镜头C需要稳定第一帧承接信封落桌。
- 当前生成单元：镜头A+B合在 `GU-001`，镜头C为 `GU-002`。

## 合格轻量回显

当前结果：这三镜不应平均分配时长。A镜保留到“坐”说完并让林舟的拒绝停顿成立；B镜必须容纳绕椅、放下信封和摄影机停稳，切点放在信封离手且落桌声完成后；C镜从主任已经看向信封的稳定状态进入，保留“看信封—判断—抬眼”后再离开。三个切点分别服务命令压力、动作结果和主任反应，不需要为每句对白另补正反打。

必要修订：`GU-001` 同时承载台词、停顿、复杂绕行和物体接触，建议拆成两个新生成单元；旧 `GU-001` 标记被替代，正式新ID由 `shot-visual-design` 写回时建立。`GU-002` 成员未变，保留原ID。

现在请你决定：A镜在林舟开始移动前保留较短的拒绝停顿，还是保留更长停顿，让主任的命令先显得真正压住了他？

下一步：按你的决定完成 `ERT-DEMO-SBG012@v001` 与 `ERC-DEMO-SBG012@v001`；我只提出修订，不直接改分镜，写回后再进入逐镜摄影审核。

## 不合格表现

- 把三镜都设为相同秒数，理由只写“节奏统一”。
- 因为出现对话就自动补一组正反打。
- 把切点只写成“动作后”或“情绪点”，没有可定位时机。
- 拆分生成单元后继续沿用 `GU-001` 给新的成员集合。
- 直接改分镜 CSV、替镜头设计决定新机位，或在剪辑卡预造正式 Prompt ID。
- 同时询问 Profile、停顿长度、是否拆单元和是否改机位，制造多个决定点。
