# 剪辑与节奏

## 进入前

只在本剪辑与节奏阶段列出剪辑 Profile、代表作品、成熟度与证据边界，询问用户是否调取。无明确选择时只用已确认的通用方法。Profile 影响节奏判断方法，不机械复制成片平均镜头长度，也不继承过去项目选择。

## 决策

1. 依据已落地在导演调度、场戏表演与镜头叙事功能中的戏剧变化而非均分时长确定切点；核对它们携带的 `DSB@版本 + BDT@版本` 来源一致，但不绕过上游直接读取节拍成果或其 Profile 审计区。
2. 优先保留人物完成动作、听见信息、判断和反应所需时间。
3. 判断切在动作前、动作中、动作后、视线、声音或信息揭示点。
4. 安排反应镜时说明它提供的新信息，不自动为每句对白做正反打。
5. 检查动作匹配、视线、银幕方向、道具接触和声音连续。
6. 用声音桥或画外反应连接需要连续但视觉应跳转的镜头。
7. 按当前 Seedance 2.0 工作配置将镜头划为单镜头或多镜头生成单元；镜头组总时长与各镜时长一致。
8. 高风险多人、复杂接触、长对白和大幅视角切换优先拆分，避免一个生成单元过载。
9. 含 VFX 时核对本镜必须可见的形成、传播、接触、消散/残留阶段能否在既定时长内读清。时长或生成负载不足时建议延长、切开或拆分生成单元；不得删改 VFX 身份、重排既定因果或替 `vfx-asset-production` 发明新阶段。

## 输出

- 镜头顺序、时长与生成单元
- 每个切点的情绪/信息理由
- 动作与声音接点
- 上一单元尾状态和下一单元首状态
- 需要补拍/补资产项

不重新设计机位，也不直接改写分镜 CSV。输出剪辑节奏卡后，由 `shot-visual-design` 作为唯一写入者更新镜头数量、顺序、时长、切点和生成单元，再送 `cinematography-direction` 做逐镜摄影审核。生成单元拆分或合并时标记原单元被替代，并为新单元建立新的生成单元 ID；仅重排但成员不变时保留原 ID。若节奏问题源于镜头功能重复，退回 `shot-visual-design`；若必须改变场戏目标、信息顺序或人物调度，再返回对应上游。

剪辑节奏卡交付后关闭完整剪辑 Profile。下游只接收镜头关系、时长、切点、动作/声音接点和生成单元切片，不接收 Profile 短卡、主体姓名、片名或未采用方法。
