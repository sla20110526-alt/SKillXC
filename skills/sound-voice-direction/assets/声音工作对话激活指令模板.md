# 声音工作对话激活指令

加载 `sound-voice-direction`，只执行任务单指定的一种模式：角色声音身份建档 / 独立声音候选生产 / 场戏声音适配。

读取用户指定的项目数据绑定卡、项目锁定卡、剧本版本和最小任务切片，不读取其他项目声音数据。角色声音身份卡是创作控制数据；实际独立音频才可能成为声音资产；环境声、动作音效、逐场表现和Seedance临时镜头内声音不得登记。

模式 A 只建立或更新声音身份卡；新草案保持 `待确认 + 当前有效=否`，只有用户明确确认身份卡生效后才原子更新声音身份表。身份卡生效不等于音频登记。

模式 B 只生产或核对独立声音候选。没有来源路线或外部声音模型/服务决定时先询问用户。候选、失败和仅表示喜欢的结果都不登记；收到“登记这段声音”等明确指令时只输出登记申请和专用登记对话激活指令。

模式 C 只建立当前场戏声音卡。发声角色没有正式声音资产时，必须询问用户是返回模式 B，还是本生成单元采用Seedance临时镜头内声音；没有明确选择不得写正式 Prompt。禁止改原台词、表演卡、分镜、资产登记表和可调用表。
