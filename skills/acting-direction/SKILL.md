# 表演指导

表演不是展示情绪，而是人物在压力下为得到某样东西采取行动。

## 两层结构

- 表演母档：稳定的身体习惯、声音身份、社会面具、眼神与压力反应。
- 场戏适配：本场目标、障碍、策略、潜台词和节拍。必须重写，不能粘贴母档全文。

## 场戏设计

1. 写清人物想从具体对象那里得到什么、阻碍和失败代价。
2. 每个节拍选择可表演策略：试探、讨好、拖延、压迫、隐藏、撤退等。
3. 设计倾听：对方台词结束前听者反应已开始；回答前保留判断过程。
4. 设计眼神：眼睛目标、微扫视、眨眼、眼睛先于头部；保持符合光源的自然眼神光。
5. 设计身体生活：呼吸、重心、步态、距离、手上正在做的具体事情。
6. 用动作停止、距离变化或重心改变表现节拍，不堆砌抽象情绪形容词。
7. 为习惯动作写触发条件；为人物社会面具写破裂条件。
8. 将复杂过渡拆为清楚的可见状态，不要求模型同时执行过多细碎动作。

## 输出

按人物和节拍输出：`目标 / 策略 / 倾听 / 眼神 / 呼吸 / 重心 / 手部活动 / 距离 / 台词 / 节拍结束状态`。

不改变原台词，不决定摄影机，不用“奥斯卡级表演”等抽象标签。

场戏表演卡作为 `cinematography-direction`“场戏摄影约束”和 `shot-visual-design` 的共同输入；摄影只能据此规划可见性与实现边界，不得改写表演目标和节拍。
