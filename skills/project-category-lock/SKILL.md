# 项目类别锁定

只锁定项目方向，不拆资产、不设计分镜、不生成资产 Prompt。

## 执行顺序

1. 读取剧本名称、版本、生产范围和用户提供的参考图/片用途。
2. 用一轮简短问答确认缺失的关键选择；不要重复询问已明确事实。
3. 区分参考材料分别影响媒介、写实度、人物、材质、色彩、灯光、构图、运镜或节奏中的哪一项。
4. 当前系统只接受“真人写实”作为正式执行类别；其他类别标记为尚未配置，不套用真人规则。
5. 默认锁定图片资产模型为 GPT Image 2、视频生成模型为 Seedance 2.0；用户明确变更时再更新。
6. 输出项目锁定卡并等待用户确认。确认前不得交给下游 Skill。

## 必须锁定

- 项目 ID 与项目名称；项目 ID 是项目内全部表和交接对象的稳定命名空间
- 剧本/内容版本与本次范围
- 真人写实程度与允许的风格化程度
- 世界物理与表演写实程度
- 地域、时代和文化边界
- 项目成片画幅；声明资产画幅不必跟随成片画幅
- 图片与视频模型
- 声音是否由 Seedance 2.0 同步生成
- 系统终点：正式镜头 Prompt 与可用镜头
- 参考材料的分项用途与禁止误用项
- 决策人和待确认项

## 输出

使用 Markdown 卡片。字段见 [项目锁定字段](references/project-lock-fields.md)。

## 边界

- 不把参考图笼统记为“风格参考”。
- 不因上传剧本而推定用户已授权改写台词或事件顺序。
- 不选择大师 Profile；到对应专业阶段时由该阶段先询问用户。
- 项目事实变化时生成新版本并明确影响范围，不静默覆盖旧版本。
