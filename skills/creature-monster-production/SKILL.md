# 特殊生物与怪物资产生产

首次进入前说明当前生命体、基础/变体模式和预期交付，询问用户是否确认使用。图片模型固定为 GPT Image 2。

## 输入门

- 项目绑定卡、需求槽位、预留正式资产 ID、剧本功能与关联场次
- 生物来源、尺度、栖息环境、智能/行为边界和现实/超自然程度
- 当前有效风格/美术短卡与用户参考
- 已登记父形态和附加道具精确版本
- 必须继承、允许变化、禁止变化
- 必要的动物行为、解剖、生物力学、医学或物理顾问结论

缺少会改变物种身份、轮廓、运动或变体因果的信息时暂停。需要用户或顾问补齐的字段见[生命体身份与运动约束](references/creature-identity-motion.md)。

## 生产模式

1. **基础形态**：先锁定生命体身份，不混入剧情伤势、环境污迹或释放特效。
2. **结构变体**：肢体数量、骨架、器官、角翼尾或体型发生身份级变化时，建立独立预留 ID 和父子关系。
3. **状态变体**：伤口、感染、湿润、灼伤、衰弱等继承精确父版本，只改状态。
4. **持物/穿戴组合**：附加对象先正式登记，再由本 Skill 保持生命体身份并定义接触。
5. **转化过程**：转化前后形态分别作为生命体资产；中间的能量、烟尘、组织流动或破坏时序交 `vfx-asset-production` 与正式镜头 Prompt。

以可识别人类脸和人物表演为核心的类人角色优先交 `character-asset-production`。边界不清时返回 `world-asset-production`，不得两个 Skill 同时改同一身份。

## 身份设计

- 用轮廓、质量分布、骨架/关节、承重肢、头面识别点和表皮分区定义身份。
- 每个器官和附肢都要有生长位置、连接方式、活动范围或明确的非生物规则；避免装饰随机堆叠。
- 区分左右对称规则与固定不对称识别点，防止跨视图漂移。
- 明确眼、口、呼吸器官、感觉器官和攻击/防御结构的静止状态；眼部反光必须来自已定义光源。
- 指定站立、爬行、飞行、游动或多模式切换时的重心、步态、关节范围、速度上限和惯性。
- 写清皮肤、毛发、鳞片、甲壳、黏膜、骨质等材料边界及接触环境后的变化。

## 交付

先制作一张生命体身份总览卡：以可读 3/4 主视图为主，按需要加入侧/背轮廓、尺度参照和身份细节。所有视图必须是同一基础状态，不把运动连拍或多个转化阶段当作同一个身体。

同时输出文字版运动约束卡，供导演调度、表演、镜头与 Seedance Prompt 使用。运动卡不是图片资产，不单独登记；结构图或状态图只有在用户明确登记后才成为可调用资产。

## Prompt 与检查

把确认后的身份卡定义、运动静止姿态、参考用途和继承清单交 `image-prompt-production`。复核轮廓、尺度、肢体计数、关节连接、对称规则、表皮分区、脸部/头部锚点、地面接触和跨视图一致性。不要用“可怕、史诗、真实怪物”等情绪词替代结构。

## 登记与返工边界

失败候选不登记；用户给出调整方向或参考后重做完整设计/Prompt输入。只有明确登记措辞才输出登记申请。父形态或附加道具变化后，本 Skill 只复核兼容性，不更改登记状态；失败原因只在用户明确要求时记录。

## 输出

- 生命体身份设计卡与单张总览卡定义
- 文字版运动约束卡
- 变体继承/转化阶段拆分
- GPT Image 2 Prompt 装配输入与检查清单
- 用户明确登记后的登记申请，或返工方向
