# 生命体身份、解剖与运动约束

## 身份事实门

最少核对：生命体是什么、剧情功能、来源规则、自然/人工/突变/感染/超自然边界、栖息环境、智能与行为范围、数量、体长/高度、质量级别和尺度依据。剧本未说明时区分用户锁定、顾问结论、创作建议和未知。

以下缺口会改变身份或运动，必须暂停：主要身体分区、承重方式、关键肢体/器官数量、感觉与呼吸方式、主要运动模式、固定不对称、攻击/防御结构、环境介质或转化终点。不能用“外星”“怪异”“可怕”代替这些决定。

## 形态定义

每个基础形态和结构变体建立独立 `形态定义ID@版本`。使用生命体自身坐标表达前/后/左/右/上/下；图像屏幕左右变化不改变解剖侧别。锚点至少覆盖：

- 远景轮廓、头/躯干、承重肢、骨架/关节和质量中心
- 眼、口、感觉、呼吸、攻击、防御和交流结构
- 角、翼、尾、触手、鳍、甲片或其他附肢的数量、根部连接和活动范围
- 皮肤、毛发、鳞片、甲壳、黏膜、骨质或人工组织的表皮分区
- 固定对称规则与个体不对称识别点
- 握持、穿戴、骑乘、拖曳或装置连接所需接触锚点

从单张图无法确认的背面、内部器官或隐藏连接写 `未知禁止补写`。创作建议先标 `推断待确认`；顾问结论记录适用范围，不把现实动物规律强行套到已锁定超自然规则上。

## 解剖与材料检查

- 每个承重肢都能把质量传到支撑面；关节方向和活动范围不互相穿透。
- 每个附肢都有根部、生长/连接方式、静止归位和运动路径；无功能装饰也明确固定规则。
- 软组织厚度、表皮张力和皱褶服从骨架、肌肉、重力和接触，不像独立贴片漂浮。
- 湿润、黏液、血液、反射和半透明只出现在有来源的分区；不要把所有表面做成同一塑料高光。
- 眼神光、发光器官和环境反光分别记录；没有发光规则时不得把眼睛或皮肤变成自发光。

## 运动约束

为每个形态建立稳定 `运动约束集ID@版本`，并绑定形态定义、预留正式资产 ID 及登记后的精确生命体版本；再为每个实际需要的主要模式单独建行：站立、行走、奔跑、跳跃、爬行、攀附、飞行、滑翔、游动、钻行或其他。每行写：

1. 起始静止姿态、支撑/接触点和质量分布。
2. 发力部位、第一动作、关节范围和步态/振翅/摆尾节律。
3. 速度级别、加减速、转向、制动和惯性；没有依据时不用虚构精确数值。
4. 地面、水体、空气、植被、建筑或对象的接触、反作用和可见痕迹。
5. 呼吸、皮肤、毛发、软组织、尾翼和其他附肢的次级运动。
6. 镜头中必须保持可辨的身份锚点、禁止动作和超自然例外。

`未验证` 或 `资料不足` 的运动约束不能被下游写成确定动作。Seedance Prompt 只提取当前镜头所需的一种运动模式及必要转折，不复制整张运动表。

## 行为与场戏表演边界

本数据记录物种/形态稳定的感觉范围、警戒距离、捕食/防御、群体关系、注意方式和动作惯性。重要叙事生命体此刻想得到什么、采取何种策略、何时倾听或改变行动，由 `acting-direction` 做场戏适配；空间路线、距离和观众视点由 `directing-blocking` 决定。两者不得让生命体执行运动表明确禁止的动作。

## 版本影响

形态定义或锚点改变时，复核对应正式形态、状态、持物穿戴组合、运动约束集、场戏调度、分镜和正式 Prompt。运动能力、限制或物理规则实质改变时升级运动约束集并复核下游；只修正错字或路径不升级。只改变运动规则不自动建立新的图片资产版本；若图片身份实际改变，仍需新候选和用户明确登记。
