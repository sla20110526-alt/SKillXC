# 转化阶段与对象交互规则

## 转化阶段拆分

按以下顺序判断：

1. 阶段能否稳定停留，而非只存在于连续运动中的瞬间。
2. 阶段是否会在多个镜头或场次被直接调用。
3. 阶段是否拥有与前后不同的稳定轮廓、身体拓扑、承重或运动能力。

三项成立时建立独立结构变体槽位、预留正式资产 ID 和形态定义。只是局部拉伸、组织迁移、烟尘遮挡、能量包覆、碎裂或光线过渡时，不建立静态生命体资产；把起点/终点、持续时间、物质/能量来源、环境接触和禁止跳变交 `vfx-asset-production` 与正式镜头 Prompt。

转化终点不得在同一张总览卡混入起点残影、多个头部阶段或运动连拍。每张正式卡只表达一个可调用实体形态。

## 结构变体与状态变体

- 身体拓扑、固定器官/附肢数量、稳定体型、承重系统或永久缺肢变化：结构变体。
- 皮肤/组织损伤、感染阶段、湿润、灼伤、衰弱、僵硬、暂时功能受限或完整尸体：生物状态变体。
- 状态最终形成新稳定拓扑时，从决定性阶段起另建结构变体；不要在同一正式 ID 内悄悄换角色。

## 持物与穿戴组合

只在固定穿戴、长期绑定、近景接触反复出现或接触结构容易漂移时建立正式组合。短暂普通触碰可在镜头阶段同时调用生命体卡与对象卡，不强建组合资产。

组合卡必须写：

- 父生命体与全部附加对象精确版本
- 生命体接触锚点、对象接口锚点、侧别、方向和相对尺度
- 握持/包覆/绑缚/骑乘/拖曳方式、接触面积、遮挡和安全间隙
- 重量、承载、摩擦、反作用、运动限制和脱离条件
- `PRESERVE EXACTLY / CHANGE / ONLY CHANGE`

组合图中生命体形态错误返回本 Skill；对象结构或接口错误返回 `prop-vehicle-production`。不得同时在两个 Skill 修同一张候选。
