# 生成版本记录

默认不运行。生成失败、用户提出调整方向或上传参考资料，均不等于授权记录。

## 触发

仅在用户明确要求记录、保存版本、建立失败条目或汇总复盘时执行。

## 记录范围

- 生成批次 ID、日期和目标需求槽位/镜头
- 模型和可确认的平台设置
- 完整 Prompt 与所用参考文件
- 结果文件路径或可唯一识别信息
- 用户明确描述的失败现象、调整方向或通过结论
- 下一版本与上一版本的单变量/多变量变化

不要擅自替用户定义失败原因。可以在明确标记为“AI诊断”的字段提出分析，但不得冒充用户结论。

## 输出

使用 `assets/生成版本记录模板.csv`。记录不进入正式资产登记表，也不能使结果成为可调用资产。

项目结束复盘时允许从各对话的标准摘要汇总，但先说明可访问范围；不可访问的旧对话标为缺失，不虚构。
