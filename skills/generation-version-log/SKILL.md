# 生成版本记录

默认不运行。生成失败、用户提出调整方向、上传参考资料或在生产对话中确认状态，均不等于授权本 Skill 写项目文件。

## 两种记录模式

### A｜镜头生产进度同步

用于最低负担地保存当前做到哪里。只有用户明确说“同步本对话进度”“登记本组进度”“把这些进度写入项目记录”或在专用记录对话中明确要求汇总同步包时执行。

1. 先读取项目数据绑定卡，核对同步包、项目 ID、任务/对话来源和版本链。
2. 按 [分镜、正式 Prompt 与可用镜头的版本状态规则](../production-router-handoff/references/shot-prompt-version-state.md) 区分 Prompt 状态与生成结果状态，不把“通过”统一写成一个状态。
3. 用户确认“镜头可用”即可写 `可用`，不要求上传视频；当前 Prompt 版本的结果同时写 `结果当前采用=是`，除非用户明确说只是备选、暂留或不采用。没有文件路径时保持 `可用结果定位` 为空，把结果依据类型写为 `用户明确确认` 并保存用户原文。
4. 每个 `项目ID + 正式PromptID + Prompt版本` 在进度表中只保留一行当前状态。更新前保留原表可恢复副本；新 Prompt 版本建立新行，上一版的 `Prompt状态` 标为 `已替代`、`Prompt当前有效` 标为 `否`，但不得自动改变旧版生成结果状态或 `结果当前采用`。用户决定旧结果不再采用时才更新该字段。
5. Prompt 和生成结果分别保存依据类型与原文，更新一方不得覆盖另一方依据。`待人工检查` 由正式 Prompt 交付产生，Prompt 依据写 `系统交付`；生成结果初始状态写 `系统初始化`。Prompt 放行、需返修和结果可用必须保存相应用户原文，不得冒充系统判断。
6. 只写同步包明确包含的范围；不可访问或含糊的对话标缺失，不推断状态。
7. 进度表固定写入绑定项目数据根目录下的 `records/镜头生产进度表.csv`；首次获同步授权时才建立 `records/` 和空表，不在项目绑定阶段预建。
8. 在临时完整表中应用同步包，使用 `assets/shot-production-progress.schema.json` 检查；通过后保留原表的可恢复副本，再替换绑定项目中的正式进度表。写入后再次检查，失败时恢复原表，不留下部分更新。
9. 使用 `assets/镜头生产进度卡模板.md` 输出同步范围、缺失项、表路径和校验报告。

生产对话不得直接执行上述写表。它只使用 `assets/镜头生产进度同步包模板.md` 输出同步包；收到明确同步指令时，再附 `assets/镜头进度记录对话激活指令模板.md`，由专用记录对话执行。

### B｜详细生成版本记录

仅在用户明确要求“记录失败原因”“保存这次版本”“记录完整 Prompt/参数/参考”或建立详细项目复盘时执行。范围可以是图片资产、Seedance 镜头或独立声音候选；外部声音服务的候选也必须有项目需求槽位或说话者范围，不能因为用户上传音频就自动建记录。

详细模式记录范围：

- 生成批次 ID、日期和目标需求槽位/镜头
- 模型和可确认的平台设置
- Prompt 类型、稳定 Prompt ID/版本、完整正文与所用参考文件；图片使用 `图片PromptID`，视频使用 `正式PromptID`，声音服务没有既有稳定 ID 时以本记录任务建立的本地 Prompt ID 明确标识
- 结果文件路径或可唯一识别信息
- 用户明确描述的失败现象、调整方向、Prompt 放行结论或生成结果结论
- 下一版本与上一版本的单变量/多变量变化

不要擅自替用户定义失败原因。可以在明确标记为“AI诊断”的字段提出分析，但不得冒充用户结论。

## 数据边界

进度同步与详细记录是两张独立表。进度同步不要求复制完整 Prompt、参考输入、平台参数、结果文件或失败原因；详细模式才使用 `assets/生成版本记录卡模板.md`、`assets/生成版本记录模板.csv` 与 `assets/generation-version.schema.json`。两种模式都按 [项目数据三层契约](../production-router-handoff/references/project-data-contract.md) 检查并把报告写入绑定项目目录。

镜头进度记录不是资产登记，不进入正式资产登记表或可调用资产表。`可用` 表示用户确认该生成镜头可进入当前项目后续使用；`结果当前采用` 表示它当前是否被项目选择，二者不得与 Prompt 的有效性混用。它不表示视频成为图片/声音参考资产；如果用户以后要把视频或提取音频作为参考资产，仍须走对应资产登记流程。Schema 通过不替代用户状态结论。

项目结束复盘时允许汇总各生产对话导出的标准同步包，但先说明可访问范围；不可访问的旧对话标为缺失，不虚构。
