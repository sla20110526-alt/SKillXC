# 影视大师 Profile 资料库

## 强制调用规则

1. 到导演、美术、剧作或剪辑的方法建立阶段，以及摄影的“全片摄影基线”模式时，先列出该分类当前可用 Profile。
2. 询问用户是否调取以及选择谁；未明确选择时不读取 Profile，只运行通用 Skill。
3. 默认最多一个主 Profile。需要补充 Profile 时，必须让用户确认，并限定到具体局部问题。
4. Profile 只在当前专业阶段发挥作用；阶段完成后只向下游传递短执行卡，不传完整资料。
5. 不因过去项目选过某 Profile 就在新项目自动沿用。

## 摄影 Profile 生命周期

- 常规询问点只有 `cinematography-direction` 的“全片摄影基线”模式。选择后把方法压缩进全片摄影规则卡，随即关闭完整 Profile。
- “场戏摄影约束”、`shot-visual-design`、“逐镜摄影审核”和 `video-prompt-production` 只继承全片/场戏摄影卡，不重新列候选、不重复询问、不读取完整 Profile。
- 只有用户明确要求摄影重释，或现有规则无法完成已经成立的场戏风格断裂，才可提出场戏例外。必须先说明冲突规则、例外内容、精确场次/镜头范围和失效点，得到用户明确确认后才读取指定 Profile。
- 场戏例外不得静默覆盖全片摄影规则卡；范围结束后自动回到全片基线。

## 使用方法

- 先读 [资料库目录](references/catalog.md)，再只读用户选择的 Profile。需要核查证据边界时读 [资料来源](references/sources.md)。
- 将 Profile 中的方法与当前剧本、空间、资产和生产限制重新推导，禁止机械复刻镜头或堆叠姓名。
- 输出：本项目采用的方法、舍弃的方法、作用范围、与项目事实的冲突、短执行卡。
- 引用具体作品时说明所提取的是该作品方法，不把它冒充创作者在所有作品中的固定风格。

## 累积新 Profile

用户提供新参考时：

1. 确认创作者、作品、部门和具体参考片段。
2. 区分可观察事实、可靠访谈/资料和分析推断。
3. 按 [Profile字段](references/profile-schema.md) 建卡，并记录资料来源与分析推断。
4. 标记资料成熟度：`提纲 / 初版 / 已核验 / 项目验证`。
5. 新资料不得静默改写旧 Profile；更新版本并注明变化。

## 边界

Profile 是专业决策辅助，不是要求模型“照某位在世创作者的风格生成”的标签。优先使用可执行的视点、空间、光线、调度、节奏和材料语言。
