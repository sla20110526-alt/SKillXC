# Thelma Schoonmaker｜剪辑 Profile

资料成熟度：初版。代表作：《愤怒的公牛》《好家伙》《无间行者》。

## 方法

- 以演员表演、心理能量和人物主观节奏决定镜头长短。
- 在平静、爆发、幽默和暴力之间使用鲜明速度变化。
- 音乐、旁白和环境声可以组织时间蒙太奇，但不替代场戏因果。
- 接受突然切断或强烈并置，让观众体验人物不稳定或世界残酷。
- 长镜头与快速蒙太奇并存，取决于人物何时控制或失去控制。

适用：人物能量、犯罪、主观叙事、速度变化。风险：表面快速剪辑会压缩AI表演所需的反应时间。

短卡：跟随表演能量；速度有反差；强切有心理理由；给反应留时间。
