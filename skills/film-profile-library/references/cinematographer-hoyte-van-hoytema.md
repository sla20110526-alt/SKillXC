# 霍伊特・范・霍特玛｜摄影指导 Profile

资料成熟度：初版。代表作：《锅匠，裁缝，士兵，间谍》《星际穿越》《奥本海默》。

## 方法

- 让大画幅的尺度感同时服务宏观空间和近距离面部，不把宏大等同于远景。
- 以真实地点、实拍质感和材料表面建立可信世界。
- 使用浅景深、近距离和遮挡营造主观压力或信息选择。
- 在低调自然主义和巨大事件之间保持人物身体存在。
- 器材选择必须转译为透视、颗粒、景深和观看距离结果。

适用：宏大题材、科技/历史、内心压力、实景规模。风险：只写 IMAX 或大画幅没有执行意义。

短卡：规模与面部并存；实景材料；选择性焦点；器材语言转成可见结果。
