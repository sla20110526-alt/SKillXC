# Aaron Sorkin｜编剧／剧作 Profile

资料成熟度：初版。代表作：《社交网络》《史蒂夫・乔布斯》。

## 方法

- 把对白组织成目标明确的攻防、回避、重定义和地位变化。
- 通过职业任务、时间压力和公共场合迫使私人冲突外化。
- 平行时间或重复事件用于改变观众对人物动机的理解。
- 高信息密度仍需清楚的说话目标、听者反应和节拍转折。
- 让语言能力本身成为人物的武器、盔甲或缺陷。

适用：谈判、职业精英、法务/科技、快速对白、权力交锋。风险：Seedance长对白承载有限，应拆分并保留倾听与停顿。

短卡：对白即行动；职业压力外化私人冲突；每轮语言改变地位；高速中保留听者。
