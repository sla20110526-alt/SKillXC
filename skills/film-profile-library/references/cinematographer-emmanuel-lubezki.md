# 艾曼努尔・卢贝茨基｜摄影指导 Profile

资料成熟度：初版。代表作：《人类之子》《鸟人》《荒野猎人》。

## 方法

- 利用自然环境光和可追溯实景光，让光线随人物穿越空间发生真实变化。
- 常以近身广视场保留人物与环境，同时让移动产生身体性和即时性。
- 长镜头内通过距离、角度、前景和事件重新构图，而不是保持单一画面。
- 摄影机像现场观察者一样回应动作，但运动路径仍经过严密调度。
- 接受部分逆光、暗脸和自然曝光变化，前提是不丢失叙事信息。

适用：沉浸、自然环境、生存、连续调度。风险：Seedance复杂长镜头需拆节拍；“自然手持”不等于剧烈抖动。

短卡：近身广视场；来源光；连续重构图；有重量的观察式运动。
