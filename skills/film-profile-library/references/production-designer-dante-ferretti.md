# Dante Ferretti｜Production Design Profile

资料成熟度：初版。代表作：《纽约黑帮》《飞行家》《雨果》。

## 方法

- 以完整街区、建筑层次和丰富物质细节建立可生活的历史世界。
- 让手工、商业、阶层、交通和时代技术同时出现在环境中。
- 用大尺度空间容纳群体、仪式、表演和复杂摄影机运动。
- 细节密度有前中后景层级，关键叙事区域仍保持可读。
- 历史重建允许戏剧性强化，但材料和工艺必须相互一致。

适用：历史城市、工业时代、群体场面、浓厚物质世界。风险：对小场戏使用过高细节密度会抢夺人物注意力。

短卡：完整历史生态；材料工艺一致；密度分层；场景支持群体与运动。
