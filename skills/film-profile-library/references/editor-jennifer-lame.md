# Jennifer Lame｜剪辑 Profile

资料成熟度：初版。代表作：《海边的曼彻斯特》《信条》《奥本海默》。

## 方法

- 根据人物心理将记忆、现在和并行事件组织成可感知的关联。
- 允许情绪在切镜后继续发酵，不急于用反应镜解释。
- 在复杂时间结构中用声音、动作、主题问题和视觉对应提供方向。
- 大量信息段落与安静人物时刻形成节奏对比。
- 非线性不是装饰，每次跳转都改变当前场景的理解。

适用：记忆、创伤、多时间线、复杂信息。风险：Seedance单次生成不承担宏观非线性，应在分镜/生成单元层组织。

短卡：时间跳转改变意义；情绪跨切延续；复杂结构用声音与动作定向。
