# Billy Wilder / I. A. L. Diamond｜编剧／剧作 Profile

资料成熟度：初版。代表作：《热情似火》《公寓春光》。

## 方法

- 给人物明确而冲突的欲望，让谎言、伪装或交易不断产生新的实际后果。
- 场景尽早进入冲突，尽量以反转、决定或新的麻烦离开。
- 道具、职业规则和空间不仅制造笑料，也推进关系与因果。
- 喜剧建立在人物认真追求目标上，不要求演员表演“好笑”。
- 在尖锐反讽后保留人物脆弱和道德选择。

适用：喜剧、爱情、职场、身份错位、苦涩人情。风险：只追求机智台词会损伤潜台词和真人反应。

短卡：欲望冲突；谎言有后果；场次晚进早出；笑料来自行动；反讽下保留人性。
