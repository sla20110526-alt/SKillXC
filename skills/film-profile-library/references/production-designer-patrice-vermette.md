# Patrice Vermette｜Production Design Profile

资料成熟度：初版。代表作：《降临》《沙丘》《沙丘2》。

## 方法

- 从文化、气候、资源、技术和权力结构推导建筑与物件，不从装饰拼贴世界观。
- 使用统一几何、尺度和材料语法连接地点、载具、服装与技术。
- 让巨大空间保留功能区、路径和人物尺度参照。
- 未知文明通过形状、表面、重力/方向和使用方式表现差异。
- 地形、风沙、雾气和光线作为设计系统的一部分，而非后加特效。

适用：科幻、未知文明、宏大世界、文化建构。风险：符号过多会让 GPT Image 2 产生无规则奇观。

短卡：世界由条件推导；统一几何材料；规模有参照；环境与建筑一体。
