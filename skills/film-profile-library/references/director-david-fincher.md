# 大卫・芬奇｜导演 Profile

资料成熟度：初版。代表作：《七宗罪》《十二宫》《社交网络》。

## 方法

- 用精确的空间、视线和程序性行动组织信息，不靠摄影机随意寻找事件。
- 摄影机运动通常服务揭示、跟随信息或维持不安的控制感；避免无动机漂移。
- 让人物在工作流程、调查、谈判和重复行为中暴露性格。
- 通过克制表演、对话攻防和环境细节累积压力，而非频繁情绪特写。
- 保持观众理解空间，但控制其何时获得关键事实。

适用：调查、犯罪、程序性叙事、权力谈判、冷峻都市。风险：机械套用会让需要温度和即兴感的场戏过度僵硬。

短卡：精确调度；摄影机有信息动机；克制反应；程序塑造人物；环境持续施压。
