# Dennis Gassner｜Production Design Profile

资料成熟度：初版。代表作：《毁灭之路》《007：大破天幕杀机》《银翼杀手2049》。

## 方法

- 用少量巨大、清楚的建筑形体定义类型世界和人物尺度。
- 把现实材料、功能结构与未来/类型化造型融合，避免无功能装饰。
- 场景轮廓、入口、纵深和地标服务追逐、对峙与摄影机路径。
- 用水、玻璃、混凝土、木材、金属等材料差异建立情绪区域。
- 控制环境信息密度，让关键物件和人物轮廓可读。

适用：犯罪、动作、未来都市、建筑主导的类型片。风险：宏大形体若缺少生活痕迹会像概念图而非真实场所。

短卡：功能性大形体；材料分区；地标清楚；规模服务动作和孤立。
