# Sarah Greenwood｜Production Design Profile

资料成熟度：初版。代表作：《赎罪》《安娜・卡列尼娜》《至暗时刻》。

## 方法

- 从人物阶层、社会礼仪和历史压力建立空间，而不只复制年代装饰。
- 让色彩、尺度、陈设密度和空间秩序随人物关系变化。
- 在写实历史基础上允许有明确概念的舞台化重构，但保持规则统一。
- 用门、长廊、楼梯、房间层级和家具距离支撑调度与权力关系。
- 服装、建筑、物件和表面老化共享同一社会经济逻辑。

适用：历史、阶层、文学改编、现实与舞台化结合。风险：只复制华丽陈设会丢失人物与空间因果。

短卡：阶层塑造空间；历史细节服从人物；陈设支持调度；概念化必须有统一规则。
