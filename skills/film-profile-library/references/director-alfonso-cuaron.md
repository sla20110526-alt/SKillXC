# 阿方索・卡隆｜导演 Profile

资料成熟度：初版。代表作：《人类之子》《地心引力》。

## 方法

- 让人物行动、环境事件和摄影机观察在连续时空中共同推进。
- 通过前中后景同时发生的信息建立世界，而不是逐项切特写解释。
- 摄影机贴近人物身体风险，但会暂时离开主体观察环境后再返回。
- 长镜头必须含有节拍、空间变化和观看选择，不等于单纯延长时长。
- 在高复杂调度中保持明确的生存目标和空间方向。

适用：沉浸式危机、灾难、生存、人物与环境强关联。风险：没有可靠空间图和动作分层时，长镜头会过载 Seedance。

短卡：连续时空；环境主动叙事；近身但不只盯主体；运动随危险和信息转移。
