# Margaret Sixel｜剪辑 Profile

资料成熟度：初版。代表作：《疯狂的麦克斯：狂暴之路》。

## 方法

- 高速动作仍保持视觉中心、移动方向、目标和危险来源清楚。
- 切点跟随动作能量和因果，同时保留足够画面让观众读懂接触结果。
- 景别与角度变化建立节奏，但相邻镜头共享清晰的动作接点。
- 反应、机械细节和环境后果用于解释动作重量与风险。
- 加速来自信息明确，不来自无差别缩短镜头。

适用：追逐、战斗、多人动作、机械动作。风险：Seedance镜头过短会降低身份与动作稳定，需以生成单元为约束重构。

短卡：视觉中心稳定；银幕方向清楚；动作因果连续；速度不牺牲可读性。
