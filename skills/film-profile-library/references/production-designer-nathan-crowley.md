# Nathan Crowley｜Production Design Profile

资料成熟度：初版。代表作：《致命魔术》《黑暗骑士》《星际穿越》。

## 方法

- 从真实工程、机械和城市功能出发建立可信的类型空间。
- 优先可使用、可进入、可驾驶、可破坏的结构，而不是纯表面造型。
- 通过大型实物、明确尺度和功能细节让科技或奇观具有重量。
- 城市、基地、载具和设备共享同一技术年代与制造逻辑。
- 为动作和摄影机预留路径、转折、遮挡和危险区域。

适用：现实主义科幻、城市动作、机械装置、大型实景。风险：功能主义若缺少人物生活层会显得冷硬同质。

短卡：工程可信；结构可使用；尺度真实；世界共享制造逻辑。
