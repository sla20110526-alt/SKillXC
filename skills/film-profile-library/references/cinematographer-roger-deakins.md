# 罗杰・迪金斯｜摄影指导 Profile

资料成熟度：初版。代表作：《老无所依》《边境杀手》《银翼杀手2049》《1917》。

## 方法

- 优先建立单一、可追溯的主光方向和清楚空间，不用无来源补光装饰人物。
- 选择简洁而有叙事位置感的构图，让人物与地形、建筑或空白形成关系。
- 摄影机运动克制且有任务；需要沉浸时保持路径和节拍精确。
- 暗部允许存在，但保护叙事所需的轮廓、眼神或动作信息。
- 色彩与光线来自场景世界和时间状态，而不是通用调色标签。

适用：犯罪、边境、战争、严肃类型、空间清晰。风险：把“克制”误解成所有镜头固定或低照度。

短卡：一个主光逻辑；构图简洁；空间清楚；运动有任务；暗部有选择。
