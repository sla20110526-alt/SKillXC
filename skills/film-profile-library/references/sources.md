# Profile 资料来源

当前初版优先使用行业机构和工会资料核对创作者、部门、作品和专业方法；Profile 中未单独引用的“方法”均视为分析性推断，等待后续逐作品、逐访谈核验。

## 通用行业来源

- 导演与作品：[BAFTA Director](https://www.bafta.org/awards/film/director/)、[BFI Sight and Sound](https://www.bfi.org.uk/sight-and-sound/directors-100-greatest-films-all-time)
- 摄影指导：[American Society of Cinematographers](https://theasc.com/)
- Production Design：[Art Directors Guild](https://adg.org/)
- 编剧与剧本：[Writers Guild of America](https://www.wga.org/writers-room/101-best-lists)
- 剪辑：[American Cinema Editors](https://americancinemaeditors.org/)、[Academy Awards Database](https://awardsdatabase.oscars.org/search/)

## 后续升级要求

每个 Profile 升级为“已核验”前，至少补充：

1. 两项创作者本人或核心合作者访谈/讲座。
2. 所选代表作中的具体场景和时间点。
3. 可观察方法与推断之间的区分。
4. 与当前 AI 模型执行能力之间的适配测试。
5. 不适用场景和失败样本。
