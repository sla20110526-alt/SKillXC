# 王家卫｜导演 Profile

资料成熟度：初版。代表作：《重庆森林》《花样年华》《春光乍泄》。

## 方法

- 从人物主观记忆、欲望和错过组织时间，不必让情绪严格服从钟表连续。
- 借走廊、门框、镜面、前景遮挡和拥挤空间表达亲近与不可接近。
- 让重复动作、物件、地点、音乐或环境声积累情感差异。
- 使用画外信息和未说完的行为，让关系存在于留白。
- 动态模糊、速度变化等只在表达主观时间时使用，不作为普遍滤镜。

适用：欲望、记忆、都市孤独、关系错位。风险：表面复制霓虹、慢动作会变成装饰，且可能破坏剧本清晰度。

短卡：主观时间；遮挡与距离；重复中的变化；留白；感官线索服务关系。
