# Adam Stockhausen｜Production Design Profile

资料成熟度：初版。代表作：《为奴十二年》《布达佩斯大饭店》《西区故事》。

## 方法

- 根据项目在历史写实、图像化构图和舞台化空间之间选择明确程度。
- 通过色彩区域、建筑轴线和层次清楚地组织人物走位。
- 让年代细节、社会环境和使用痕迹支撑人物生活，不做博物馆陈列。
- 对高度风格化项目保持比例、图案和色彩的一致语法。
- 在大型场景中保留可拍摄区域、转换路径和群体调度空间。

适用：年代重建、音乐/群体调度、构图型场景、风格化现实。风险：对真人写实项目过度对称或饱和会产生模型化布景感。

短卡：历史可生活；色彩和轴线组织调度；风格化遵守统一比例语法。
