# 摄影指导

## 进入前

从 `film-profile-library` 列出摄影 Profile 和代表作品，询问用户是否调取。每次只允许一个主 Profile；补充 Profile 必须限定到明确镜头特征。

## 决策顺序

1. 明确镜头叙事任务、观众视点和与人物的情绪距离。
2. 先决定摄影机物理位置、距离、高度、侧别和遮挡关系。
3. 再决定视场与透视：环境扩张、人物压迫、背景压缩或中性观察。
4. 决定景深和焦点转移是否承担信息变化。
5. 决定曝光保护对象及人物与实际光源的关系。
6. 决定固定、三脚架、肩扛、无稳定器手持、稳定器、轨道或载具运动。
7. 每镜只保留一个主要运镜意图，写明触发点和停止点。

## 输出语言

优先描述可观察结果：摄影机与人物距离、视场宽窄、前后景比例、背景压缩、步伐反馈、景深结果。毫米焦段可以作为辅助，不得只写器材名或“电影感”。

## 短执行卡

输出全片摄影原则、不同场景的允许变化、手持尺度、暗部策略、镜头运动禁区和供 `shot-visual-design` 使用的摄影卡。

摄影不负责决定场戏信息顺序，也不修改人物调度；上游不成立时退回对应 Skill。
