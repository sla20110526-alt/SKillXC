# 人物五视图总览卡

## 排版

- 使用一张横向总览卡，资产画幅按排版需要选择，不继承项目画幅。
- 左侧三分之一：上方正面特写，下方3/4视角侧面特写。
- 右侧三分之二：正面全身、侧面全身、背面全身并列。
- 侧面全身与3/4侧面特写使用同一侧方向；若角色左右识别点不同，优先显示剧情重要侧。

## 一致性

- 同一人物身份、年龄、骨相、五官比例、发际线、耳朵、肤色和发型。
- 同一身高感、头身比、肩宽、四肢比例和体态。
- 同一服装结构、颜色、材质、缝线、配件数量和佩戴位置。
- 中性表情、自然闭嘴、眼神清醒；深色眼睛保留微弱自然眼神光。
- 中性低反差光、统一纯净背景；不要戏剧光、环境叙事或强轮廓光。
- 全身图不裁头顶、手、鞋或脚底，不用夸张动作。

## 用途

总览卡是 Seedance 2.0 的单人物多视图参考资产。标签应短且不遮挡人物；如果文字准确性影响人物生成，优先无标签版。
