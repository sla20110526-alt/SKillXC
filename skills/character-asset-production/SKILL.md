# 人物资产生产

首次进入前说明本 Skill 将使用 GPT Image 2 生产哪些人物候选，并询问用户是否确认使用。

## 固定模型和边界

- 图片模型：GPT Image 2。
- 人物资产画幅按总览卡排版决定，不跟随项目成片画幅。
- Seedance 2.0 每个人物调用一张五视图总览卡，不规划五张人物参考上传。

## 流程

1. 读取人物需求槽位、人物事实、人物风格短卡和 GPT Image 2 模型卡。
2. 先生产选脸剧照候选。深色眼睛仍需分辨虹膜/瞳孔，并有符合光源的微弱自然眼神光。
3. 等待用户明确“登记这张”等指令；未登记脸不得制作正式基础卡。
4. 基于已登记脸制作一张五视图总览卡。
5. 检查五视图一致性，等待明确登记。
6. 从已登记基础卡派生服装/妆造版本；从正确服装父版本派生雨湿、流血、伤口、污迹、战损等状态。
7. 每次编辑列出 `严格继承 / 允许变化 / 只改变`，不得重画底层脸。

## 五视图排版

读取 [人物五视图总览卡](references/character-overview-card.md)。固定内容：正面特写、3/4视角侧面特写、正面全身、侧面全身、背面全身。

## 登记门

“不错、继续、这个方向、就用这张”不自动登记。失败图不登记；用户给调整方向或参考图时直接修订，只有用户要求才记录失败原因。
