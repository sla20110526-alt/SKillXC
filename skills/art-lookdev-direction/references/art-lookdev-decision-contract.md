# 世界设计推导与四层边界

## 1. 最小事实矩阵

每次只提取当前范围需要的事实，不重读整套项目资料。无法确认的项目写“未知”，不要用惯例补齐。

| 事实维度 | 必问内容 | 影响的美术决定 |
|---|---|---|
| 时间 | 年代、季节、剧情跨度、建造／购置时间 | 工艺可得性、老化阶段、替换层次 |
| 地域 | 国家／城市／乡村、气候、地貌、运输与供应 | 建材、服装、对象来源、污染与维护 |
| 阶层 | 所有者、使用者、收入、权力、获得渠道 | 空间尺度、陈设密度、服装质量、维修方式 |
| 功能 | 空间／服装／道具承担什么实际任务 | 动线、储物、开合、承重、耐用与使用痕迹 |
| 职业与习惯 | 谁使用、频率、熟练度、规训和个人改造 | 磨损位置、收纳秩序、身体适配、非对称细节 |
| 剧情状态 | 事件前后、占用、破损、缺失、天气影响 | 场次状态、连续性和是否需要资产变体 |
| 项目意图 | 观众关系、真实度边界、跨部门不变量 | 允许风格化范围、信息密度和禁区 |

每个重要决定使用下列链条：

`事实出处 → 社会／功能含义 → 物质规则 → 可观察结果 → 适用层级 → 责任Skill → 检查方法`

例如“工薪家庭”不是设计结果。需要继续推导为：稳定还是临时收入、住房所有权、物件替换能力、维修习惯与空间功能，最终形成可观察的材料、陈设、服装和对象差异。

## 2. 部门设计矩阵

### 建筑、室内与陈设

- 先写功能分区、尺度、动线、私密／公共边界、储物和使用者，再写风格。
- 区分原始建造层、后期改造层、临时修补层和当前占用层；不要把所有物件做成同一年代和同一新旧程度。
- 陈设密度必须由人数、职业、获得渠道、空间权力和维护能力解释。
- 空间结构及锚点的逐视角生产由 `location-spatial-production` 完成；美术只规定物质与社会逻辑。

### 服装与妆造

- 分开身份基线、职业／阶层、季节功能、身体适配、个人维护、剧情状态和场次连续性。
- 写轮廓、层级、基材、制作方式、合身程度、维修与重复穿用；不要用品牌或“高级感”替代。
- 妆造只定义人物世界中的生活与身份结果；脸部身份、五视图和具体服装资产由 `character-asset-production` 完成。

### 道具、载具与图案文字

- 写功能、来源、制造时代、尺度、重量、获得难度、维护、使用者改造和文字／图案依据。
- 英雄道具、近景文字、跨镜识别或动作因果对象需要正式资产；一次性普通物件可以保持类别规则。
- 具体结构、部件、文字校对和交互锚点由 `prop-vehicle-production` 完成。

### 材质与工艺

- 每种材料区分基材、成形／连接工艺、表面处理、固有色、粗糙度、反射边界、维修替换和污染反应。
- 不把“木头、金属、布料”当完成定义；说明是哪类材料、为何可得、怎样加工、如何老化。
- 材质反射边界可交摄影／灯光做曝光与受光实现，但美术不规定光源位置。

### 老化、磨损与污迹

- 先找因果：触摸、摩擦、负重、日晒、雨水、油烟、泥土、盐分、热、维修和清洁。
- 再写位置、方向、强度、边缘、层次、时间差和维护痕迹；磨损不能均匀撒满全表面。
- 区分身份型长期痕迹、资产状态变化、场次临时污染和镜头短暂效果。

### 固有色与色彩角色

- 美术只定义材料／物体固有色、跨资产分布和叙事职责；灯光定义现场色温、受光颜色和曝光结果。
- 用“谁持有、出现在哪里、何时增加／减少、与什么形成层级”说明主色、辅色、强调色，不强制百分比。
- 当固有色与灯光方案冲突时，先保留美术身份，再由摄影和灯光提出实现；不得在下游静默改色。

### 视觉母题

- 每个母题写物质载体、第一次出现、重复条件、变化方式、叙事职责、使用上限和禁用俗套。
- 母题必须能落到建筑线型、图案、材料、对象排列或服装结构；不能只写抽象名词。
- 单镜构图重复或光影图案不自动成为美术母题，除非它有跨资产物质载体。

## 3. 四层判定

依次询问：

1. 这项变化是否改变项目世界长期存在的建造、制造、阶层、材料或母题语法？是则归“永久世界规则”。
2. 它是否只规定某一类资产怎样继承永久规则，而不定义某个具体候选？是则归“资产类别规则”。
3. 它是否由明确剧情因果产生，并需在一场或多镜中持续？是则归“场次美术状态”；需要复用时建立正式资产状态版本。
4. 它是否只在一个镜头短暂可见、不改变资产身份且无需跨镜延续？是则归“镜头临时效果”，交 VFX／灯光／镜头或 Prompt。

同一对象可以同时受四层约束，但每条决定只能有一个主层级。例如“墙体使用当地石灰抹面”是永久规则；“贫民住宅墙面修补方式”是资产类别规则；“爆炸后墙体焦黑破损”是场次状态；“爆炸瞬间飞尘”是镜头临时效果。

## 4. 顾问缺口

每个缺口选择：

- **必须准确**：错误会破坏年代、地域、职业、法律、物理、安全或剧情因果；未核查前阻断相关决定。
- **允许艺术化**：真实边界已知，可以在写明偏离范围后设计。
- **纯虚构规则**：现实资料只供可理解性参考，由项目锁定其内部一致性。

顾问问题至少写：稳定缺口 ID、剧本出处、当前假设、为什么影响美术、准确性等级、最晚决策点、安全回退、责任专业和返回节点。已有结论只精确引用任务成果 `ID@版本`，不要把顾问结论混入长期控制卡直接上游集合。

## 5. 冲突判定

- 与项目风格意图冲突：返回 `style-lock-director`，不要在美术层改变项目观众关系。
- 与事实或顾问结论冲突：先修事实／顾问依据，再重做受影响美术规则。
- 与摄影实现冲突：美术保留物质身份，摄影说明视场、透视或曝光实现问题；不能由任一方单方面改写另一方职责。
- 与灯光实现冲突：美术保留固有色、材质与来源灯具身份，灯光修正受光、反射和曝光；需要改变物体本体时返回美术。
- 与资产可生产性冲突：分类资产 Skill 返回具体结构或交付问题；美术只改本体规则或执行切片，不代做 Prompt 补丁。
