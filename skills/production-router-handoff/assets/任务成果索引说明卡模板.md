## 边界

- `任务索引.csv` 只追踪任务单与调度状态；`任务成果索引.csv` 只追踪任务产物，两者通过来源任务 ID/版本形成一对多关系。
- `可交接 + 当前有效=是` 只表示责任 Skill 已完成本版成果且允许下游精确引用，不等于用户批准、正式资产登记、Prompt 放行或生成结果可用。
- 上游换版只能先做只读影响分析；未经责任 Skill 复核，不得自动把成果继续使用、升级版本或判定已经修复。
- 一个项目、一个成果 ID 最多只有一个当前有效版本；新版本激活时旧当前版进入已替代，停用新版不自动恢复旧版。
