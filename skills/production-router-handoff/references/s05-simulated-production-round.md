# S05 模拟生产回合

## 后台条件（不向用户整表展开）

- 项目已绑定，类别为真人写实，图片模型为 GPT Image 2。
- 当前任务是为角色林默选择脸母图；任务、预留资产 ID、风格切片和候选编号均可唯一定位。
- 用户刚说：“第二张脸可以，就用这个继续。”
- 系统硬规则要求只有“登记这张”“确认登记”等明确措辞才触发登记。

## 轻量生产模式应答

当前步骤：角色脸母图确认

本轮结果：已把第二张保留为当前候选；这句话没有触发正式登记。

现在请你决定：

- 继续用第二张制作人物五视图前，请明确选择：还要调整这张脸，还是登记第二张为“林默脸母图”？

下一步：调整则按你的方向返修；明确登记则生成登记申请和专用登记对话短指令。

## 不应出现在这个回合

- 完整项目绑定卡、任务单、Schema、CSV 行或索引表头；
- 所有后台 ID、路径、指纹和校验日志；
- 一次列出人物、场景、道具、表演、摄影等后续全部 Skill；
- 把“就用这个继续”改写成“确认登记”；
- 直接修改正式资产登记表或可调用资产表。

## 严格记录分支

只有用户随后明确说“登记第二张为林默脸母图”时，生产对话才冻结第二张候选、正式名称和用户原文，输出登记申请及短激活指令。正式三表事务仍由独立 `approval-asset-registry` 对话执行；完成后返回登记回执，生产对话再继续五视图任务。
