# 最小交接对象

## 项目数据绑定卡

提供项目 ID、项目数据根目录、登记表相对路径、资产文件根目录、绑定版本与确认状态。未绑定项目只能生成待确认卡，不能登记正式资产。

## 项目锁定卡

提供全项目不应被下游改变的事实。

## 创作任务单

提供当前单元目标、完成定义、输入版本、允许与禁止变化、输出格式、格式例外和责任 Skill。摄影相关任务还要写明三种工作模式之一、全片/场戏摄影卡引用及 Profile 继承或例外状态。每张任务单使用稳定任务 ID 和任务单版本，并在 `任务索引.csv` 留一行；索引通过 `handoff-task.schema.json` 检查。

逐镜交接遵循单写入规则：`shot-visual-design` 生成并修改分镜表，`cinematography-direction` 只返回逐镜摄影审核卡。审核结论为摄影技术修正时，仍由前者写回并重新做结构检查。

涉及正式镜头生产时，任务单携带分镜组 ID/版本、镜头 ID/版本集合、生成单元 ID 和正式 Prompt ID/版本。状态解释与版本递增使用 [分镜、正式 Prompt 与可用镜头的版本状态规则](shot-prompt-version-state.md)。

涉及表演时，任务单选择“角色表演母档”或“场戏表演适配”之一，并携带表演母档 ID/版本。重要角色没有当前有效母档时先建立母档；简单角色跳过时写明理由。母档与场戏卡都由 `acting-direction` 唯一写入，不进入资产登记。母档版本的确认生效和表格更新使用[表演控制对话激活指令](../../acting-direction/assets/表演控制对话激活指令模板.md)在项目专用对话中完成；普通场戏对话只读当前有效母档。

涉及发声角色时，任务单选择“角色声音身份建档”“独立声音候选生产”或“场戏声音适配”之一，并携带声音身份卡 ID/版本。实际音频候选另携带需求槽位、预留正式声音资产 ID、来源/授权和外部声音模型或服务决定；场戏适配另携带正式声音资产 ID/版本与调用方式，或用户确认的临时声音原文。身份卡不进入资产登记；临时镜头内声音只有被单独形成音频文件并收到明确登记指令后，才另走登记申请。

涉及世界资产时，任务单必须写资产工作模式、正式资产类型和唯一责任生产 Skill。明确单一类别使用“直接分类生产”，交人物、场景、道具/载具、生物/怪物或VFX对应 Skill；只有混合或类别不清时才使用“世界资产二级路由”并交 `world-asset-production`，且该路由任务的返回物只能是拆分、依赖和顺序。组合候选必须携带全部已登记基础资产精确版本，不能把未登记的多个身份一次生成后再补依赖。

人物任务还必须从“选脸与脸母图、五视图基础卡、服装妆造版本、剧情状态版本、人物—道具交互、版本兼容复核”中选择一个工作模式。选脸槽位和五视图槽位使用不同预留正式资产 ID；五视图任务携带已登记脸母图精确版本，后续变体/交互携带正确父人物版本和全部附加资产版本。未完成专用登记回执时不得把上一层候选写成正式输入。

场景任务还必须从“场景母图、空间圣经建档或更新、预制剧情视图、专项或英雄视图、场景状态变体、光影状态、版本兼容复核”中选择一个工作模式。场景母图另写“默认3/4空间母图”或用户明确要求的“剧照式母图”；后者必须携带用户原文。视图、场景状态和光影状态分别使用独立预留 ID，并携带已登记母图/状态/视图精确版本；空间圣经、锚点表、投影表和光源地图只作为任务数据交接，不进入正式图片资产表。

道具/载具/图案文字任务还必须从“基础对象、对象状态变体、图案文字母版、对象表面应用、对象装配、交互接口定义、载具舱内接口交接、版本兼容复核”中选择一个对象工作模式。产图任务另写交付形态。表面应用携带一个已登记同类型父对象和全部图案文字母版；装配携带主承载对象与全部已登记部件；交互接口与舱内接口只作为任务数据交接，不进入正式图片资产表。

生物/怪物任务还必须从“基础形态、结构变体、生理状态变体、持物穿戴组合、运动约束定义、转化阶段拆分、版本兼容复核、登记回执绑定”中选择一个生命体工作模式。产图任务交付一张生命体总览卡；结构变体携带一个已登记基础/上一结构形态，状态变体携带状态发生前的已登记生命体，组合携带生命体父版本及全部已登记道具/载具。形态定义、解剖锚点和运动约束集只作为任务数据交接；运动约束集必须绑定预留/正式生命体版本。登记回执产生正式版本后，登记对话不代写任务数据；路由器应建立“登记回执绑定”任务，完成生产卡、解剖表和运动表绑定，才能进入下游。转化中可停留且跨镜复用的阶段另建结构变体，单镜过渡交 VFX 与正式 Prompt。

## 镜头生产进度同步包

生产对话只输出当前对话可确认的 Prompt 与生成结果状态，不直接写表。用户明确要求同步时，交接包还应携带同步指令原文和[镜头进度记录对话激活指令模板](../../generation-version-log/assets/镜头进度记录对话激活指令模板.md)；专用记录对话核验后写入绑定项目的镜头生产进度表。

## 登记申请

创作 Skill 只能输出候选结果说明；登记申请不是批准。必须等待用户明确登记命令。申请至少携带项目 ID、绑定卡路径、预留正式资产 ID、用户指定资产名、唯一候选、用途和登记指令原文；正式写表由独立登记对话完成。

专用登记对话的激活指令使用 `approval-asset-registry/assets/登记对话激活指令模板.md`，要求加载 `approval-asset-registry`，读取指定绑定卡和登记申请，只执行核验、写表、可调用映射与回执；禁止继续资产创作或修改候选。

## 可调用资产切片

只列当前任务实际需要、在正式资产登记表与可调用资产表均为 `可调用`，且资产状态传播表没有未处理依赖冲突的正式资产 ID、版本、文件、平台引用名和用途。每个派生资产同时携带生产依据和当前兼容依赖；状态为待复核、停用或历史时禁止下传。

## 创作控制版本切片

长期项目基线、表演母档与声音身份只列 `已生效 + 当前有效=是` 的稳定卡片 ID、项目版本、适用范围、源定义引用和Profile引用。中央源/Profile与项目卡版本独立；不得用中央目录“最新版”静默替换项目固定引用。场戏节拍、调度、表演、摄影约束、剪辑和声音短卡仍由任务索引按稳定 ID/版本追踪。

## 新对话激活指令

说明只读取上述最小材料；禁止切换项目数据目录、重新拆剧本、改项目类别、改预留正式资产 ID 或自行登记。

## 数据校验报告

交接包说明本次使用的 Markdown 卡片、CSV、Schema、数据契约版本和校验报告路径。报告通过只代表结构通过；批准授权、跨表 ID、依赖与版本有效性仍由责任 Skill 检查。
