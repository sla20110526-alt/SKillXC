# 专业点、领域与证据合同

## 1. 先判断这是不是顾问问题

只有外部专业知识会改变当前创作决定时才进入顾问路由。以下内容先返回原责任节点：

- 剧本究竟写了什么、事件顺序或角色状态不清：`script-truth-index`。
- 用户想采用哪种虚构设定、价值立场或情绪效果：用户与对应创作责任 Skill。
- 机位、构图、运镜或剪辑选择：镜头／剪辑责任 Skill。
- 已确定设计是否在 Prompt 中漏译：图片或视频 Prompt Skill。

不要把一般创作犹豫包装成“请多个专家会诊”。一个顾问问题必须能指向：具体原文、一个待决定字段、错误代价、最晚返回节点。

## 2. 准确性三分法

按错误后果而不是题材外观分类：

| 等级 | 判据 | 未完成时怎样处理 | 允许的下游动作 |
|---|---|---|---|
| 必须准确 | 错误会破坏年代地域、身份功能、职业／法律／医学程序、物理因果、安全或剧情成立 | 阻断相关决定；可靠资料不足时保持未知 | 只采用“可靠可采用”的事实切片 |
| 允许艺术化 | 现实事实内核可定位，项目只需有边界地偏离 | 先核验事实内核；写偏离对象、幅度、理由、禁区 | “有条件采用”并同时继承条件 |
| 纯虚构规则 | 项目明确不声称现实真实性，只需内部一致 | 返回用户／创作责任 Skill 锁定；必要时只问可理解性与安全 | 标为项目自定义，不写成现实事实 |

一个句子可能包含三类内容，必须拆成不同主张。例如“真实的急救顺序保持可信，但报警灯颜色可艺术化，虚构医院内部代码由项目锁定”不能用一个“允许艺术化”覆盖。

## 3. 最小专业领域

每个问题包只能有一个主领域。领域名称用于找到合适资料或专业人士，不代表自动拥有答案。

| 主领域 | 典型问题 | 常见返回节点 |
|---|---|---|
| 历史档案与年代物质文化 | 制度、时代可得性、年代用物 | 美术、道具、服装 |
| 地域语言宗教与民俗 | 称谓、方言、礼仪、禁忌、地域习俗 | 剧作、表演、美术、调度 |
| 建筑材料工艺与保护 | 构造、加工、维修、空间功能 | 美术、场景、道具 |
| 职业程序与法律 | 岗位流程、权限、法域、文件与程序 | 剧作、资产、调度 |
| 医学法医与生理 | 伤情、反应、时间过程、法医可见结果 | 表演、妆造、VFX、镜头 |
| 物理工程机械与车辆 | 结构、尺度、运动、承载、故障与结果 | 道具载具、场景、VFX、镜头 |
| 动物行为生态与生物力学 | 支撑、步态、环境互动、群体行为 | 生物、表演、调度、镜头 |
| 军事武器战术与安全 | 制式、角色权限、非操作性使用后果、安全 | 道具、调度、镜头 |
| 特技VFX现象与现场安全 | 可见阶段、现场可实现性、安全隔离 | VFX、灯光、调度、镜头 |

次领域只有在以下三个条件同时成立时才允许存在：同一裁决不能合理拆成另一个问题包；次领域会改变答案而非只增加背景；问题包写明次领域的唯一问题和失效点。否则将它排除或另建问题包。默认不超过一个次领域。

## 4. 问题写法

合格问题采用：

`在【精确时代／地域／人群／场景条件】下，为决定【唯一字段】，需要核实【可裁决主张】；请给出【答案形式】、【适用范围】、【来源定位】和【不确定性】，不要提供【危险或越权细节】。`

不合格写法包括“这个真实吗”“找历史、医学、物理专家看看”“怎么做得更专业”。问题包还必须说明无结论时采用暂停、删除细节或不依赖该事实的保守方案中的哪一种。

## 5. 来源层级与证据强度

来源按本次主张记录，不建立脱离语境的永久排行榜：

1. 权威规则或原始档案：现行法规／标准、官方档案、原始记录；仍要核对版本、法域和适用对象。
2. 一手专业资料：专业人士对当前问题的可定位答复、制造／医疗／工程原始资料、可核验的一手制作资料。
3. 同行评审或专业组织：适用于科学、医学、工程等经过专业审查的解释与共识。
4. 用户提供可定位资料：可以很强，也可能只代表特定项目；必须保留来源身份、版本和定位。
5. 可信二手专业解释：可用于背景或交叉核对，不应单独承担高风险、易变或争议裁决。
6. 未核验线索：搜索摘要、无出处转述、模型记忆、影片画面、社交帖子；只能帮助找正式来源，不能直接形成事实结论。

证据强度判断同时考虑：是否直接回答主张、来源是否有资格、是否独立、是否适用于当前时代／地域／人群／物件／法域、是否存在未解冲突、是否仍在有效期。

- **强**：直接且适用的权威／一手证据，关键冲突已处理；或多个真正独立、适用的高质量来源收敛。
- **中**：证据一致但较间接、范围有限或主要来自可信二手解释；可支持可逆的艺术选择，不足以自动放行高风险硬事实。
- **弱**：仅有线索、类比、同源转述或适用范围存疑。
- **不可用**：无法定位、明显不适用、冲突未解、已经失效或内容本身不支持该主张。

来源数量不是评分公式。同一新闻稿的十次转述仍是一份来源；一份直接适用的现行标准可能比多份泛化文章更强。证据判断必须写理由。

## 6. 结论状态

| 状态 | 最低条件 | 下游处理 |
|---|---|---|
| 可靠可采用 | 结论与证据直接对应，适用范围明确，无重大未解冲突；必须准确／高风险问题达到相应专业要求 | 可采用精确事实切片，仍继承适用条件 |
| 有条件采用 | 事实内核已有支持，但艺术化偏离、适用限制或待复核条件必须一并携带 | 只能连同条件和禁区采用 |
| 暂不可裁决 | 无可靠资料、冲突未解、来源不适用、危险问题缺少合格复核或问题本身不可安全回答 | 只作为缺口／阻断；不能写进正式事实或Prompt |

“纯虚构规则”可以形成清楚的内部一致性建议，但其现实事实栏必须写“不适用”，并标明由谁确认项目规则。它不能借“可靠可采用”伪装为现实世界结论。

## 7. 危险内容降维

顾问任务只需使观众看到可信结果，不需要教会现实实施。危险问题改写为以下安全问题：

- 会出现哪些非操作性的可见／可听现象与时间顺序？
- 人物、环境和连续性会承受什么后果？
- 哪些表现会明显违背常识？
- 现场拍摄、资产设计和VFX需要避开什么风险，需谁复核？

不得记录步骤、配比、剂量、关键尺寸／阈值、采购或改装路线、规避侦测、提高伤害、解除安全装置等能明显提高现实实施能力的内容。即使用户把行为设定为虚构，现实可迁移的危险细节仍保持受限。

## 8. 下游采用和失效传播

下游引用格式：`CCR-...@v### #CLM-### / 【采用字段】`。它必须同时携带结论状态、适用范围和必要条件，不能只复制一句结论。

顾问结论卡是独立任务成果，不是项目长期控制卡的直接上游。长期风格卡在独立“顾问任务成果引用集合”精确引用它；普通资产、调度和镜头成果在自身卡片或任务单引用它。结论卡再精确引用问题包和证据集，避免下游重复搬运全部资料。

出现问题包换版、关键来源更新／撤回、法规标准变化、剧本适用条件变化、新的一手资料或下游扩展到原范围外时，先做只读影响复核。影响分析不能自动认定旧结论失效或兼容；由本 Skill 给出 `可继续 / 需建立新版 / 暂不可裁决` 后，才走任务成果索引状态事务。
