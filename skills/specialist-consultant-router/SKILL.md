# 专业顾问路由

## 路由而非全知补写

1. 从剧本事实和当前任务识别会影响可信度、安全性或剧情因果的专业点。
2. 分为：必须准确、允许艺术化、纯虚构规则。
3. 判断需要哪类顾问，不同时加载无关领域。
4. 把问题写成可回答的具体清单，附剧本出处、当前假设和决策截止点。
5. 有权威资料时记录来源和适用范围；资料冲突时不得擅自裁决为项目事实。
6. 输出顾问结论卡，交回美术、资产、调度或镜头 Skill。

## 重点领域

历史年代、服饰工艺、建筑空间、语言称谓、宗教礼仪、军事战术、武器操作、医学伤情、法律程序、车辆机械、动物运动、流体/破坏/火焰/爆炸物理。

## 边界

- 不把现实危险操作扩写成可执行伤害指南。
- 不以“大师风格”替代专业事实。
- 无可靠资料时明确不确定性，并让用户决定艺术化边界。
