# 专业顾问路由

## 进入与唯一职责

先由 `production-router-handoff` 说明本轮工作模式、当前专业缺口、最小输入和预期交付，取得用户确认。没有具体项目、项目绑定、剧本／内容精确版本、原文定位或待裁决决定时，只列缺口，不生成虚构的专业结论。

本 Skill 唯一负责：拆分专业点、判定准确性等级、选择最小必要专业领域、组织可回答的问题、核验来源与证据、分离事实／推断／艺术化建议／项目虚构规则，并把结论精确回交责任 Skill。它不是“万能顾问”，不代替剧本决定、美术设计、导演调度、镜头设计、资产生产、法律或医疗服务。

剧本写了什么由 `script-truth-index` 负责；项目愿意怎样虚构由用户和相应创作责任 Skill 决定。本 Skill 不读取大师 Profile，也不以大师方法、作品惯例、模型常识或一张参考图替代专业证据。

## 每次只选一种工作模式

### A｜专业点分级与最小路由

用于首次发现专业缺口，或原问题的范围、出处、准确性等级、专业领域、当前假设、安全边界、决策截止点发生实质变化时。

1. 读取当前任务、剧本事实最小切片、原文定位、当前假设、待决定字段、下游责任 Skill 与最晚决策节点。
2. 按 [专业点、领域与证据合同](references/consultant-routing-contract.md) 将每个专业点只归为 `必须准确 / 允许艺术化 / 纯虚构规则` 之一。混合问题先拆分，不用一个等级覆盖全部内容。
3. 每个问题包只设一个主专业领域。只有同一裁决无法拆开且次领域会实质改变答案时，才增加一个次领域并逐字写明理由；其余领域不加载。
4. 使用 [顾问问题包模板](assets/顾问问题包模板.md) 输出稳定 `CQP-<项目ID>-<范围>-<序号>@v001`，写清需要什么证据、什么答案格式以及哪些内容不得回答。
5. 纯虚构规则如果只需内部一致性，直接返回用户和相应创作 Skill 锁定项目规则；只有需要现实可理解性或安全边界时，才保留最小顾问问题。

问题包回答的是“应核查什么、由谁核查、何时必须返回”，不构成项目事实。问题包可在业务复核后作为 `顾问任务 / 顾问问题包` 进入任务成果索引并交给用户、可靠资料检索或合格专业人士。

### B｜证据核验与结论形成

用于已有精确问题包，并收到用户资料、可定位的可靠来源或专业人士答复后。

1. 只回答当前 `CQP@版本` 的问题，不顺手扩展成百科报告。需要网络检索时优先权威机构、原始档案、法规／标准、同行评审研究、专业组织或可定位的一手制作资料；当前、易变、高风险或小众事实必须重新核验，不能依赖记忆。
2. 使用 [顾问证据记录模板](assets/顾问证据记录模板.csv) 逐项记录“来源—主张”关系，以 [consultant-evidence.schema.json](assets/consultant-evidence.schema.json) 检查结构。每条来源必须可定位，摘要使用转述，不用长篇复制原文。
3. 对来源的直接性、权威性、独立性、适用范围、冲突和时效进行判断。证据强度是本次主张的判断，不是来源永久等级；来源多不自动等于证据强。
4. 使用 [顾问结论卡模板](assets/顾问结论卡模板.md) 输出稳定 `CCR-<项目ID>-<范围>-<序号>@v001`，逐条分开：已核验事实、推断、允许艺术化建议、项目虚构规则和仍未知。
5. 结论状态只能为 `可靠可采用 / 有条件采用 / 暂不可裁决`。无可靠资料、来源冲突未解、适用范围不符或高风险结论缺少合格证据时必须为“暂不可裁决”，保留安全回退与返回节点，不得写成项目事实。

结论卡引用精确 `CQP@版本` 和证据集 `CED@版本`。结论卡完成自身业务与结构复核后进入 `tasks/任务成果索引.csv`，成果类别为“顾问任务”、成果类型为“顾问结论卡”；证据表作为“任务数据集”独立入表。`可交接` 只表示本次顾问任务输出完整，不代表法律、医疗或安全上的专业认证。

### C｜结论兼容与影响复核

用于剧本事实、问题包、来源、法规／标准、顾问答复、采用范围或下游任务发生变化后。逐条比较原结论的主张、证据、适用条件、失效条件和下游采用字段，只输出：

- `可继续`：内容不变且证据仍适用；记录复核依据，不伪造新版本。
- `需建立新版`：证据集、结论、适用范围或下游可执行切片实质变化；分别建立新的 `CED`／`CCR` 版本。
- `暂不可裁决`：新冲突或可靠性缺口无法消除；旧结论进入待复核，不得继续用于新任务。

本模式只列影响和返工节点，不直接改任务成果索引、长期控制卡、分镜、Prompt 或正式资产状态。状态事务仍由现有任务成果索引流程执行。

## 准确性等级门

- **必须准确**：错误会改变年代、地域、身份、职业／法律程序、医学或物理因果、安全边界、资产功能或剧情成立条件。相关决定在“可靠可采用”结论前保持阻断；若用户决定改为项目虚构，必须更新问题包与项目规则来源，不能静默降级。
- **允许艺术化**：先写清已知事实内核，再写允许偏离的对象、幅度、叙事理由、不得破坏的因果与安全回退。未知真实边界时不能先宣布“允许”。
- **纯虚构规则**：明确标为项目自定义，只检查内部一致性、观众可理解性和安全边界，不伪装成现实事实。虚构标签不能解除现实危险内容限制。

更详细的最小领域路由、证据梯度和状态判定见 [专业点、领域与证据合同](references/consultant-routing-contract.md)。

## 现实危险与高风险边界

涉及武器、爆炸、纵火、毒物、生物危害、自伤他伤、入侵规避、违法操作或其他现实危险时，只提供影视真实性所需的高层现象、可见后果、非操作性因果、安全禁区和合规复核需求。不得给出可执行步骤、配比剂量、关键参数、采购改装、规避侦测、提高伤害或排除安全装置的方法。

医学、法律、结构安全、特技、武器和危险 VFX 的“可靠可采用”仍要写适用法域／人群／现场条件和专业复核要求；本卡不能代替持证专业人员、现场安全负责人或法律意见。无法在不增加现实伤害能力的前提下回答时，停止技术细化，改交安全呈现和剧情结果方案。

## 下游精确引用

美术、人物／场景／道具／生物／VFX资产、导演调度和镜头设计只能引用当前 `可交接 + 当前有效=是` 的 `CCR-...@v###`，并同时填写“采用字段／主张 ID、结论状态、适用范围”。不得只写“顾问说过”“参考资料”或只复制结论正文。

- `可靠可采用`：下游可采用结论卡明确放行的事实切片。
- `有条件采用`：下游必须同时继承条件、允许艺术化范围、禁区和复核触发点。
- `暂不可裁决`：只能作为缺口／阻断依据，不得进入正式创作事实或 Prompt。

顾问结论是独立任务成果。风格、美术、摄影或灯光长期基线如需采用，只能写在“顾问任务成果引用集合”，不得写入“输入控制卡引用集合”，也不得成为四卡之间的直接上游。下游引用结论，不重复加载整份来源材料。

## 交付、版本与索引

- 问题包、结论卡和证据集分别使用稳定 ID 与独立 `v001` 起版本；旧版成果文件一经入表保持不可变。
- 问题含义、剧本出处、准确性等级、主／次领域、当前假设、适用范围、安全边界、所需证据或决策截止点实质变化时，建立下一问题包版本。
- 来源集合、来源定位、主张映射、证据强度、冲突判断变化时建立下一证据集版本；结论、确定／不确定边界、适用范围、艺术化范围、安全限制、下游采用切片变化时建立下一结论卡版本。
- 原内容不变的重复交接、只做索引状态操作或复核后继续使用不升级正文版本。中央资料或外部来源出现新版只触发影响复核，不自动改写项目结论。
- 问题包与结论卡的索引成果类别为“顾问任务”；证据表为“任务数据集”。下游精确引用只指向结论卡，结论卡再精确引用问题包和证据集。

## 返工路由与停止条件

- 剧本原文、事实 ID 或场次状态不清：`script-truth-index`。
- 项目决定要把现实事实改成虚构规则：用户确认后返回相应项目锁定／创作责任 Skill，不由顾问路由代写。
- 美术物质设计问题：`art-lookdev-direction`；资产本体问题：唯一分类资产 Skill。
- 人物视点、走位或信息揭示问题：`directing-blocking`；机位、构图或运镜问题：`shot-visual-design`。
- 来源冲突、证据不足、问题范围过大、主专业领域不唯一、次领域理由不足、决策截止点或返回节点缺失：暂停，只询问当前阻断决定。
- 危险问题要求可执行细节：拒绝该细化，保留非操作性视觉后果、安全边界和合规路由。

禁止用单一搜索摘要、无定位的模型回答、用户未确认的推测、影片画面或大师 Profile 充当专业证据；禁止把“资料不足”改写成肯定句；禁止把事实、推断、艺术化建议和项目虚构规则混写；禁止顾问卡直接修改创作成果或项目数据。

## 输出

- 模式 A：顾问问题包、准确性等级、最小主领域、必要时唯一有理由的次领域、证据请求、安全回退、截止点和返回节点。
- 模式 B：逐主张证据集、顾问结论卡、结论状态、可采用切片、未知与安全限制。
- 模式 C：兼容结论、受影响的精确成果版本、是否需新版本及唯一返工节点。

默认使用轻量生产回显，只向用户展示本轮专业点分级、必要缺口、可用结论和一个决定点；后台问题包、证据、版本与索引保持完整。
