# 对象交付与缺口

## 最小信息

- 身份与用途：它是什么、谁使用、解决什么剧情动作
- 时代地域与来源：制造年代、文化、社会阶层、制式/民用/自制
- 尺度：真实尺寸或与人物/常见物体的明确比例
- 结构：轮廓锚点、部件连接、开合/支撑/承重、前后与左右
- 材质：基材、工艺、粗糙/反射、磨损位置、污迹来源
- 状态：基础、剧情变体及不可混入基础版的变化
- 文字图案：逐字内容、语言、字体类别、行序、位置、工艺和磨损
- 使用方式：握点、重心、接触点、操作方向、移动/骑乘约束

缺少其中会改变身份或功能的字段时，列为待用户补充；可由美术方法决定的字段才交美术短卡，不把建议写成剧本事实。

## 单张对象总览卡

- 最大画面：能识别整体结构的 3/4 主视图
- 辅助画面：只加入主视图无法说明的侧/后方向或功能状态
- 细节：接口、握持、文字、机构或材质节点
- 尺度：中性人物剪影、标尺或已登记参照物；不能改变对象本体身份
- 统一：同一对象、状态、图案、磨损和光照展示逻辑

简单对象不必为了排满卡片制造多余小图；过小的身份细节应单独放大，而不是只存在于缩略全景中。

## 跨类别边界

- 人物穿戴物作为服装身份的一部分时由人物 Skill 管理；需要独立特写、交互或复用时再拆为道具。
- 载具外观和机械身份属于本 Skill；供人物在其中走位、表演和换机位的舱内属于场景空间 Skill。
- 动物、怪物和非人生命体不属于本 Skill；纯机械装置属于本 Skill，生物机械混合体先由世界资产路由确定主要身份。
- 爆炸、烟尘、能量和流体时序属于 VFX；爆炸后的物体结构状态仍属于本 Skill。
