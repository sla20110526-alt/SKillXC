# 图案文字与表面应用规则

## 先锁内容，再生成母版

将锁定剧本、用户、顾问或待确认建议中的内容依据原样写入校对表，保留语言、Unicode 字符、大小写、全半角、空格、标点、行序和书写方向。不要自动纠错、翻译、补全品牌名或把相似字符互换。内容来自创作建议或原文存在歧义时先询问用户，不伪造用户确认原文。

为每个独立版面建立稳定 `文字定义ID@版本`。纯图形也记录内容类型、图形结构、方向和禁改项；没有文字时逐字内容明确写“不适用”。

## 清洁母版

图案文字母版使用正视、无透视、无材质纹理、无磨损和足够留白的清洁画面。先检查：

1. 字符数量、字符顺序、大小写、标点和换行完全一致。
2. 图形数量、对称/非对称关系、正负形和方向一致。
3. 字体类别、字重、字宽、字距、行距、对齐和边距符合定义。
4. 不含镜像、乱码、伪文字、额外小字或模型自动署名。

只有逐字/逐项校对通过的唯一候选才可申请登记。Prompt 中“清晰文字”不能代替生成后校对。

## 对象表面应用

表面应用以前一阶段已登记母版为附加资产，并固定：

- 父对象精确版本与目标区域锚点
- 正反面、朝向、旋转、尺寸、边距和重复次数
- 平面/曲面变形、折角、接缝和遮挡
- 印刷、喷涂、雕刻、压印、刺绣、蚀刻或贴附工艺
- 与父对象磨损相符的褪色、刮擦、缺损和污染，但不改变字符身份

贴图只能出现在批准区域。对象结构、比例、基材、未授权表面和其他图案保持不变。若一个应用任务需要改变多个对象身份，返回资产计划拆成多个槽位。

## 校对结论

- `待核对`：未完成逐字/图形检查，不得登记。
- `逐字通过`：所有字符和版式通过，可进入登记门。
- `图形通过`：纯图形母版通过，可进入登记门。
- `发现错误`：候选失败或待调整，不得登记。
- `不适用`：当前工作模式不含图案文字。

表面应用完成后再次校对可见字符。磨损可以遮掉已批准部分，但不能用磨损掩盖生成错误。
