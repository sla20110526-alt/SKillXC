# 道具与载具资产生产

首次进入前说明当前对象、交付用途和拟用输入，询问用户是否确认使用。图片模型固定为 GPT Image 2。

## 输入门

- 项目绑定卡、需求槽位、预留正式资产 ID 和资产类型
- 剧本功能、时代地域、使用者、出现范围与尺度参照
- 当前有效风格/美术短卡；光影只用于展示，不改对象固有色
- 已登记父资产与附加资产精确版本
- 专业顾问结论；武器、机械、车辆或历史工艺缺关键事实时先返回顾问路由
- 必须继承、允许变化、禁止变化和用户参考

缺少会改变对象身份、功能或时代归属的信息时暂停，不用“电影感”“高级”“未来感”代替设计决定。需要用户补充的具体字段见[对象交付与缺口](references/object-deliverables.md)。

## 生产模式

1. **基础对象**：先锁定可跨镜复用的结构身份。
2. **状态变体**：破损、沾污、开启、空/满载、烧灼等必须继承精确父版本，只改剧本要求状态。
3. **图案文字**：先锁定准确内容、语言、拼写、行序、版式与工艺；作为独立图案母版或对象表面派生版本生产。
4. **交互组合**：对象本体先登记，再交保持主体身份的责任 Skill 制作持握、穿戴、骑乘或操作组合。
5. **镜头临时物**：不需跨镜识别、无近景且不影响动作因果的普通物件可只写入镜头 Prompt，不强建资产。

## 身份设计

- 先定义真实尺度、比例、轮廓识别点、重心和支撑方式。
- 结构必须解释功能：连接、铰链、开合、承重、磨损、握持/乘坐位置不能互相冲突。
- 材质写清基材、表面工艺、粗糙度、反射、边缘磨损和受力后的变化。
- 载具同时锁定轴距/轮距或等效结构、离地高度、门窗、灯具、驾驶/乘坐位置和方向性特征。
- 载具舱内若承担人物调度，另交 `location-spatial-production` 建立可拍摄空间；外观资产不得假装已经定义完整内舱。
- 图案文字必须逐字给出准确文本，禁止模型自行补字；先做清洁母版，再做印刷、雕刻、刺绣、喷涂或磨损应用版本。

## 交付视图

按用途选择最少必要视图，不默认做完整 360 度。简单道具通常使用清晰 3/4 主视图加尺度参照；复杂机械、武器和载具使用一张对象总览卡，包含 3/4 主视图、关键侧/后视图和功能细节。总览卡用于建立身份时，保持同一对象、同一状态、同一尺度逻辑，不做广告海报构图。

## Prompt 与检查

把确认后的设计卡、参考用途、视图排版及继承清单交 `image-prompt-production` 装配完整 GPT Image 2 Prompt。本 Skill 复核：轮廓、尺度、结构闭合、左右/前后方向、材质、文字、功能、状态和跨视图一致性。参考图不清或冲突时向用户说明，不擅自平均。

## 登记与返工边界

候选、失败和用户仍准备调整的图不登记；只有“登记这张”“确认登记”等明确措辞才输出登记申请。父版本变化后，本 Skill 只给出兼容性结论，不写正式状态。失败原因只有用户明确要求才转 `generation-version-log`。

## 输出

- 对象身份与功能设计卡
- 最少必要视图/单张总览卡定义
- GPT Image 2 Prompt 装配输入与生成后检查清单
- 候选说明：生产依据、参考用途、必须继承/允许变化/禁止变化
- 用户明确登记后的登记申请，或返工方向
