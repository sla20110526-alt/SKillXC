# 风格锁定总控

## 前置确认

先由 `production-router-handoff` 告知用户准备使用的通用专业 Skill，并确认是否使用。进入导演、美术和“全片摄影基线”环节时分别询问是否调取 Profile；没有明确选择就只使用通用 Skill。摄影 Profile 的常规询问只在这里发生一次，后续场戏与逐镜阶段继承全片摄影规则卡。

## 顺序

1. 核对类别锁定卡、剧本范围和参考材料分项用途。
2. 组织已确认的 `art-lookdev-direction`、`lighting-direction` 和 `cinematography-direction`“全片摄影基线”模式；摄影与灯光相互复核曝光、实际光源和暗部逻辑，专业冲突回到对应 Skill 迭代。
3. 按题材需要调用 `specialist-consultant-router`。
4. 每个专业最多一个主 Profile；只有用户确认时添加一个局部补充 Profile，并写清作用范围。
5. 选择少量 P0 测试资产：人物脸、人物五视图局部测试、主场景母图、关键材质/光源。
6. 测试未获用户确认时不扩大批量生产。
7. 把确认结果压缩为下游短执行卡，不把完整 Profile 复制进每条 Prompt。

## 输出

- 完整风格锁定包
- 人物资产短执行卡
- 场景/道具资产短执行卡
- 场景光影短执行卡
- 全片摄影规则卡
- 已用 Profile、作用范围和冲突处理记录

## 边界

- 大师姓名不是可执行风格；必须转译成空间、光线、构图、运动、色彩和节奏决策。
- 不将某部作品的所有特征机械复制到新项目。
- 完整摄影 Profile 在全片摄影规则卡形成后关闭；风格锁定总控不把它传给逐镜设计或 Prompt 生产。
- 不替用户登记测试资产。
