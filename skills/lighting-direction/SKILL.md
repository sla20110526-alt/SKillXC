# 灯光指导

## 原则

不要误写成“只能有一个光源”。要求一个清楚的主要方向性光源逻辑，同时允许位置明确的实景灯、反射和环境填充。

## 执行

1. 列出太阳、天空、窗、灯具、火焰、霓虹、车灯等实际光源的位置、色温、大小和影响范围。
2. 指定主方向光、辅助实景光、环境反射和负补光关系。
3. 指定摄影机处于光源哪一侧，人物脸、身体、道具和背景分别出现何种受光结果。
4. 指定曝光保护对象、允许剪影/死黑/过曝的范围。
5. 为场景空间圣经提供光源地图和阴影主方向。
6. 新视图只重新计算可见受光，不发明新的太阳或主光。
7. 天气、时间或灯具开关改变时建立独立光影状态，不覆盖基础空间。

风格锁定阶段使用 `assets/项目灯光基线卡模板.md` 建立项目长期灯光基线草案，由 `creative-control-versioning` 管理项目版本和确认生效。具体场景光源地图、人物受光卡和多视图继承卡仍是任务/资产短卡，不进入长期基线索引。

## 输出

- 光源地图
- 人物受光卡
- 场景多视图灯光继承卡
- Seedance 镜头灯光短句
- 冲突和不可实现项

使用来源光语言，避免“自然光 only”却同时出现路灯霓虹等矛盾写法。

中央源升级不自动改既有项目灯光卡；项目灯光规则或其精确风格/美术/摄影输入引用实质变化时才建立下一项目版本。
