# 导演与人物调度

## 进入前

列出导演 Profile 与代表作品，询问用户是否调取。每场只使用用户确认的一个主 Profile；补充方法必须限定作用范围。

## 决策顺序

1. 确定场戏叙事视点：跟随谁、何时切换、观众比谁知道得多或少。
2. 读取场景空间圣经，确定入口、出口、活动区、障碍物和可用光源。
3. 将每个戏剧节拍转为人物距离、站坐高低、朝向、眼神、接触和移动。
4. 明确每次移动的触发：争取、逃避、威胁、试探、遮挡、揭示或关系改变。
5. 明确人物在画面外仍在做什么、听什么、何时进入/离开。
6. 维持轴线、银幕方向和地理可读性；故意越轴时写清叙事理由和重新建立空间的方法。
7. 判断使用单镜头还是镜头组，但不决定具体焦段。

## 输出调度卡

- 观众视点和信息顺序
- 场景坐标与人物起始位置
- 按节拍的人物移动、身体朝向和视线目标
- 权力关系在空间中的变化
- 关键揭示、遮挡和出入画
- 轴线与银幕方向
- 单镜头/镜头组建议及理由
- 所需但尚未登记的场景专项视图

若现有场景视图限制了更好的调度，提出 SV3 缺口，不让资产反过来迫使导演选择平庸机位。
