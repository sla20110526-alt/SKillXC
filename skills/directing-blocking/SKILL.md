# 导演与人物调度

## 进入前

本阶段重新列出导演 Profile、代表作品、成熟度与证据边界，询问用户是否调取。项目风格意图阶段曾选择同一 Profile 也不构成本场授权；本场只能继承已生效项目风格规则切片。每场只使用用户本次确认的一个主 Profile；补充方法必须另行确认唯一问题、作用范围和失效点。

## 决策顺序

1. 只读取当前 `可交接 + 当前有效=是` 的 `BDT-...@v###` 逐节拍数据，以及 `DSB-...@v###` 中的成果身份、原文保护门和“给导演调度的最小切片”；两者必须精确互相匹配。继承场戏问题、逐拍触发、信息／权力变化、进出状态、不可缺失事件、锁定顺序与因果，不读取 DSB 的 Profile 采用审计区，也不得读取完整编剧／剧作 Profile、主体姓名、片名或未采用方法。缺失或待复核时返回 `dramaturgy-scene-beats`。
2. 读取当前有效表演母档的身体习惯、距离/接触边界、地位行为和弧线阶段最小切片；重要角色缺失时先返回 `acting-direction` 模式 A，不能从人物外貌临时推断。
3. 确定场戏叙事视点：跟随谁、何时切换、观众比谁知道得多或少。
4. 读取场景空间圣经，确定入口、出口、活动区、障碍物和可用光源。
   历史礼仪、职业程序、医学反应、法律权限、危险行为或其他专业事实会改变人物能否移动、如何接触或何时反应时，只采用当前可交接的 `CCR@版本 + 主张ID／采用字段 + 结论状态`；“暂不可裁决”返回 `specialist-consultant-router`，不能凭常识补调度。
   出现生物/怪物时另读取当前形态定义和本场所需运动约束集切片，调度路径、转向、接触和距离必须满足其支撑、尺度、惯性、环境介质及禁止动作；缺少可执行运动模式时返回生命体生产 Skill，不在调度中临时发明。
   VFX 会触发人物走位、躲避、观察、冲击或接触时，另读取当前 VFX 定义、时序和接触最小切片，调度只决定人物相对触发/来源/影响区的空间反应；不得改变 VFX 身份、来源、阶段或接触结果。缺少这些依据时返回 `vfx-asset-production`。
5. 将每个戏剧节拍转为人物距离、站坐高低、朝向、眼神、接触和移动；不得反向改变目标、潜台词、信息顺序或锁定因果。
6. 明确每次移动的触发：争取、逃避、威胁、试探、遮挡、揭示或关系改变。
7. 明确人物在画面外仍在做什么、听什么、何时进入/离开。
8. 维持轴线、银幕方向和地理可读性；故意越轴时写清叙事理由和重新建立空间的方法。
9. 判断使用单镜头还是镜头组，但不决定具体焦段。

## 输出调度卡

- 观众视点和信息顺序
- 场戏节拍卡与逐节拍数据精确引用
- 场景坐标与人物起始位置
- 按节拍的人物移动、身体朝向和视线目标
- 权力关系在空间中的变化
- 关键揭示、遮挡和出入画
- VFX触发/来源/影响区与人物调度接点（不适用时写明）
- 轴线与银幕方向
- 单镜头/镜头组建议及理由
- 所需但尚未登记的场景专项视图
- 顾问结论卡精确引用、采用主张／字段、结论状态和适用条件（不适用时写明）

调度卡交付后关闭完整导演 Profile。下游只继承调度卡中的观众视点、信息顺序、空间行动、轴线、揭示、禁止项和精确适用范围；不继承 Profile 短卡、主体姓名、片名或未采用方法。

若现有场景视图限制了更好的调度，提出 SV3 专项视图缺口，不让资产反过来迫使导演选择平庸机位。缺口至少写观众视点、摄影机相对锚点位置、必须可见/遮挡/离画锚点和调度用途；返回 `asset-demand-plan` 补需求槽位与预留正式资产 ID，再由 `location-spatial-production` 生产，不在导演对话直接造图。

本 Skill 不建立角色表演母档，也不把调度动作固化成人物性格。调度卡完成后先由 `acting-direction` 结合当前有效母档制作场戏表演卡，再把调度卡与表演卡交给 `cinematography-direction` 的“场戏摄影约束”模式；两张卡必须携带一致的 `DSB@版本 + BDT@版本` 来源，但不下传原始节拍成果或 Profile 审计区。随后进入逐镜视觉设计。摄影约束不得反向改变已经成立的观众视点、信息顺序、人物调度或表演目标；发现冲突时返回对应责任 Skill 讨论。
