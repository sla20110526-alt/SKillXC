# 世界资产生产路由

首次进入前说明这是二级资产路由，列出准备判断的需求槽位，并询问用户是否确认使用。只读取当前槽位及必要依赖，不加载所有资产 Skill。

## 唯一职责

把一个需求拆成可独立锁定、生产和登记的资产身份，为每个身份指定唯一责任 Skill、生产顺序和返回条件。已有明确类别的单一资产可以直接确认对应生产 Skill；不要为形式完整强制多走一次对话。

正式资产类型与责任 Skill 的机器权威映射见 `assets/asset-responsibility-map.json`。路由、排产或登记工具不得另设兜底生产者；出现映射外类型时暂停并先维护中央映射和正式资产 Schema。

| 资产身份 | 唯一责任 Skill |
|---|---|
| 真人、以人类脸和表演身份为核心的角色、人物服装妆造及人物持物组合 | `character-asset-production` |
| 可供人物进入和调度的空间、场景母图/视图、作为拍摄空间的车辆舱体 | `location-spatial-production` |
| 道具、武器、器具、可交互装置、载具本体及其图案文字 | `prop-vehicle-production` |
| 特殊生物、非人生命体、结构变体、怪物及其持物组合 | `creature-monster-production` |
| 具有可复用视觉身份的能量、烟尘、流体、破坏、粒子或超自然效果 | `vfx-asset-production` |

不确定是否需要独立 VFX 资产时，先判断它是否需要跨镜保持同一视觉身份。一次性的普通尘土、火花、运动模糊或镜头内反应直接交正式镜头 Prompt，不强建资产。

## 混合需求拆分

1. 先生产并登记基础身份，再生产派生或交互候选。
2. 人物拿武器：道具本体 → 明确登记 → 人物持物组合；组合由人物 Skill 负责锁脸、身体和服装。
3. 怪物佩戴装置：道具本体 → 明确登记 → 生物持物组合；组合由生物 Skill 负责锁定生命体身份。
4. 载具外观与可拍摄舱内：载具本体和舱内空间分别生产、分别登记，并记录彼此精确版本依赖。
5. 生物释放特效：生物基础身份 → 明确登记 → VFX视觉身份；逐镜接触和时序在正式镜头 Prompt 中组合。
6. 道具损坏与爆炸：损坏后的道具状态由道具 Skill 负责；爆炸、碎屑和光照时序由 VFX Skill 负责。

不得把两个尚未登记的身份放进同一张候选图后再倒推资产关系。

## 路由输出

- 原需求槽位和预留正式资产 ID；需要拆分时返回 `asset-demand-plan` 补建槽位和依赖，不在此临时编号
- 每个子任务的资产类型、唯一责任 Skill、完成定义和生产顺序
- 必须继承、允许变化、禁止变化
- 所需正式父资产/附加资产精确版本；缺少时暂停下游
- 需要的最小专业顾问、风格、美术、灯光切片
- 是否需要 `image-prompt-production`、用户确认点及登记返回节点

输出后二级路由结束。只有用户确认具体生产 Skill 后，才为该 Skill 生成独立任务单和新对话激活指令。
