# 世界资产生产

首次进入前说明资产类别、生产目的和预期交付，并询问用户是否确认使用本 Skill。

## 先分类

- 道具/载具：结构、比例、材质、重量、使用和损坏状态。
- 图案/文字：精确内容、位置、工艺、磨损和可读性。
- 生物/怪物：骨骼、关节、比例、表皮、对称/非对称和运动逻辑。
- VFX：来源、形态、速度、发光、烟尘/碎屑、环境接触和消散。

## 流程

1. 读取需求槽位、剧本功能、尺度参照、父资产和专业顾问结论。
2. 判断应制作独立资产、状态变体、人物—道具交互参考，还是只在镜头 Prompt 中描述。
3. 用中性、清晰、便于引用的视图制作基础候选；复杂对象按功能增加侧面、背面或细节面板。
4. 变体严格继承父版本，只改变剧情要求的状态。
5. 生物和怪物同时输出静态结构卡与供表演/镜头使用的运动约束。
6. VFX资产记录对人物、地面、空气、光线和镜头曝光的影响。
7. 等待用户明确登记；失败结果不登记，不默认写失败记录。

## 接触原则

持握、穿戴、骑乘、碰撞和破坏都必须说明接触点、重量、重心、摩擦、惯性和材质延迟。不能只写“真实物理”。
