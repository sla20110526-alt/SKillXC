# 资产需求字段

`项目ID,需求槽位ID,预留正式资产ID,资产类型,暂定资产名称,基础或变体,父需求槽位ID,父预留正式资产ID,附加预留正式资产ID集合,剧本出处,关联场次,优先级,必须继承,允许变化,禁止变化,必要交付视图,前置依赖,负责Skill,完成定义,当前状态`

`附加预留正式资产ID集合` 保存图案母版、对象装配件、人物/生物持物等非父依赖，多个 ID 使用中文分号分隔；没有时写“不适用”。每个附加依赖仍需在资产依赖关系表单独占一行，不能只藏在集合字段里。

生物/怪物结构与状态槽位使用 `生物形态依赖` 记录父链，持物穿戴组合另以 `生物交互依赖` 记录生命体父版本与 `附加对象依赖` 记录每个道具/载具；不能把全部关系只写在完成定义里。

状态只描述需求计划：`待确认 / 待生产 / 生产中 / 已有正式资产 / 暂缓`。`暂定资产名称` 不是正式登记名称；不要用“已登记”描述没有正式资产版本的槽位。
