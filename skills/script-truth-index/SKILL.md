# 剧本事实索引

把“剧本明确写了什么”与“创作者后来建议什么”严格分开。

## 输入

- 已确认项目锁定卡
- 唯一剧本版本
- 当前处理范围

## 执行

1. 为场次分配稳定 `SCN` 编号，为事实条目分配稳定 `FACT` 编号。
2. 逐场记录时间、地点、出入场人物、原台词、动作、事件和可见状态。
3. 记录服装、伤口、污迹、道具持有人、数量、左右手、声音和环境变化。
4. 对代词或省略主语只做可证实的解析；不能确认时标记歧义。
5. 每条事实记录剧本页码、段落或行范围，不以常识补成剧本事实。
6. 对新剧本版本生成差异清单，标出受影响的资产和镜头范围。

## 信息标签

- `SCRIPT_EXPLICIT`：剧本明确
- `SCRIPT_INFERRED`：由上下文高置信解析，必须说明依据
- `USER_LOCKED`：用户额外锁定
- `UNKNOWN`：待确认

不得在本索引写入 `CREATIVE_PROPOSAL`。

## 输出

- `剧本场次索引.csv`
- `剧本事实索引.csv`
- `剧本版本差异.md`（仅版本变化时）

字段见 [事实索引字段](references/truth-index-fields.md)。输出后交给 `script-asset-breakdown`，不得直接登记正式资产。
