# GPT Image 2 图片 Prompt 生产

## 定位

只把上游已确认设计翻译成 GPT Image 2 可执行语言，不重新做美术、场景空间或人物身份决策。

## 输入

- 当前任务单、需求槽位和完成定义
- 对应资产风格短卡
- 正式父资产与允许调用的参考图
- 正式父资产精确版本与全部附加依赖资产精确版本
- 必须继承、允许变化、禁止变化
- 目标排版/画幅和用途

## 生成 Prompt

1. 先写主体身份和本次唯一任务。
2. 用自然、完整、具体的语言写外观、结构、空间、材质、光线和排版。
3. 参考图逐张说明用途，避免同一图片承担互相冲突的身份、风格和构图职责。
4. 画幅、质量和输出尺寸作为平台设置单列；不要用“8K”等口号代替细节。
5. 只保留真正影响结果的禁项；优先正向描述目标状态。
6. 编辑任务采用：`CHANGE / PRESERVE EXACTLY / ONLY CHANGE`。
7. 变体必须穷尽列出脸、身体、服装、场景锚点等保持项。

## 回流

比较目标和可见结果，区分身份、结构、空间、材质、光线、排版和随机偏差。依据用户给出的调整方向重写完整 Prompt，不在旧 Prompt 尾部无限叠加补丁。

失败结果不登记、不自动保存原因。只有用户明确要求时转交 `generation-version-log`。

## 输出

- GPT Image 2 完整 Prompt
- 平台设置
- 参考图用途映射
- 继承/变化清单
- 生产依据父资产ID@版本与附加资产ID@版本
- 生成后检查清单
