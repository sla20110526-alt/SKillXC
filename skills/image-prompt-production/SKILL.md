# GPT Image 2 图片 Prompt 生产

首次进入时说明当前预留正式资产 ID、唯一责任资产 Skill、图片工作模式、准备使用的正式输入与预期交付，询问用户是否确认使用。图片模型固定为 GPT Image 2；不要重新询问模型。

默认按 [轻量生产与严格记录合同](../production-router-handoff/references/interaction-modes.md) 交付：完整 Prompt 属于本轮创作结果，可以完整显示；后台交付卡、任务成果事务和检查日志不逐项展开。面向用户只附必要参考说明、轻量检查点和一个下一步决定。

## 职责边界

- 只把上游责任资产 Skill 已确认的设计翻译成 GPT Image 2 可执行语言，不重新决定人物身份、场景空间、对象结构、生物解剖、VFX 定义、美术风格或灯光逻辑。
- 上游责任资产 Skill 是候选验收与登记申请的唯一责任方。本 Skill 只做装配、翻译核对和 Prompt 层返修，不写正式资产登记表，不输出登记申请。
- 只处理会产生一张图片候选的任务。空间圣经建档、对象接口定义、生命体运动约束、VFX 时序/接触定义、兼容复核及单镜执行条款等不产图模式不调用本 Skill。
- 默认交付可由用户手工复制到 GPT Image 2 的完整 Prompt。只有当前任务明确包含图片生成、当前会话具备对应能力且用户已要求执行时，才可在交付卡完成后调用；是否调用工具不改变版本、验收和登记边界。
- 大师 Profile 不在本阶段重新询问或加载。只读取当前有效资产短执行卡和上游已经下传的项目规则切片，不读取 Profile 短卡本体，也不把 ProfileID、名称或片单堆进 Prompt。

## 输入门

开始装配前必须具备：

- 项目 ID、绑定卡、任务 ID/版本、需求槽位和预留正式资产 ID
- 唯一责任资产 Skill、资产工作模式、目标交付形态及完成定义
- 当前版本的分类资产生产卡；其中会改变方向的缺口必须为“无”
- 已登记父资产和全部附加资产的精确 `正式资产ID@版本`；基础首版无父资产时明确写“不适用”
- 当前有效的风格/美术/资产展示灯光短执行切片及必要顾问结论；涉及已定位场景、人物融入或场景多视图时，还必须读取 `lighting-direction` 当前可交接的光源地图、人物受光或多视图继承卡。P0切片必须来自当前可交接评审卡，批量切片必须来自当前可交接风格包，且其四卡来源仍是项目当前组合
- 本轮唯一任务、参考图用途映射、`PRESERVE EXACTLY / CHANGE / ONLY CHANGE`、禁止变化与生成后检查项
- 新生成或参考编辑的工作模式、排版/画幅用途和当前平台实际支持的设置

任何输入仍使用“最新版”“上一张”“同一个人”“差不多这个场景”等无法唯一定位的表述时暂停。父或附加正式资产处于待复核、停用、历史或未登记状态时返回责任资产 Skill，不用未批准候选偷偷补齐依赖。

使用 [GPT Image 2图片Prompt交付卡模板](assets/GPT Image 2图片Prompt交付卡模板.md) 固化输入、版本和当前检查点；详细装配与分流读取 [GPT Image 2图片Prompt合同](references/gpt-image-2-prompt-contract.md)。

交付卡作为 `Prompt` 类任务成果写入任务成果索引：首次交付先为 `草案 + 当前有效=否`；用户明确说本版 Prompt 通过、确认使用，或可唯一定位地按本版进入生成后，才激活为 `可交接 + 是`。该状态只表示本版 Prompt 是当前生成依据，不等于图片候选通过、正式资产登记或生成失败记录。

## 图片工作模式

每次交付只能选择一种：

1. **新生成**：没有需要逐像素继承的父图片，用剧本事实、资产设计、短执行卡和明确用途参考建立首张候选。
2. **参考编辑**：以一个正确父资产或当前正确候选为主编辑底图，只改变已批准字段；其他参考只补充身份、结构、材质、图案文字或光影中的一个明确职责。

不要用“重做”“优化一下”“更电影感”代替模式和唯一任务。需要同时重选身份、换结构、改状态和改构图时返回上游拆分，不把多个资产阶段塞进一次生成。

## 稳定 ID 与版本

- 每个“预留正式资产 ID + 当前产图任务”建立一个稳定 `图片PromptID`，建议使用 `IPR-{预留正式资产ID}`；首次完整交付为 `v001`。
- 完整 Prompt 正文、参考用途或顺序、平台设置、上游资产卡版本、正式依赖版本发生任何会影响复现的变化时，递增图片 Prompt 版本并完整重写；上一版标为已替代，但不删除。
- 相同 Prompt、相同参考与相同设置原样再次生成时不升级 Prompt 版本。不同随机结果只是不同候选；仅在用户明确要求时交 `generation-version-log` 保存批次。
- 用户要求改变资产身份、结构、空间、解剖、VFX 阶段定义、长期风格或灯光逻辑时，先由责任 Skill 建立新的上游卡版本，再递增图片 Prompt 版本。
- 若变化实际形成新的资产角色、需求槽位或预留正式资产 ID，返回 `asset-demand-plan`；不得沿用旧图片 Prompt ID。
- 图片 Prompt 版本不是正式资产版本。Prompt 已用于生成、结果好看、用户准备继续或候选待登记，都不会产生正式 `资产ID@版本`。

## 装配顺序

1. 写主体身份、资产角色和本次唯一可见任务。
2. 按编号列参考图用途和禁止继承项，明确一个主身份/主结构底图；冲突时暂停，不把多个身份平均融合。
3. 写必须在结果中可见的身份、结构、空间、尺度、材质和状态事实。
4. 写目标排版、主体占比、视角、透视、可见面、遮挡与背景；资产展示不擅自改成叙事镜头。
5. 写已批准的展示光或光源继承、受光逻辑、反射和曝光保护。
6. 参考编辑任务依次写 `PRESERVE EXACTLY`、`CHANGE`、`ONLY CHANGE`；新生成任务也保留三段，以便定义身份锚点和唯一变化边界。
7. 末尾只保留本任务高风险禁项。优先正向写清目标，不用成串口号和泛化否定词消耗注意力。
8. 把模型、操作模式、画幅/尺寸、参考加载顺序与其他可确认设置写在交付卡的平台设置中，不把版本管理或“读取某文件”等工作流语言复制进 Prompt 正文。

资产类别的最小装配要求：

- **人物**：身份锚点优先；五视图严格保持单张总览卡版式、五面板同一人物和同一状态，眼睛保留来自既定光源的微弱自然眼神光。
- **场景**：逐项翻译摄影机卡、锚点投影、画外/遮挡、未知区、当前光源地图和多视图灯光继承卡；不得用“同一房间另一视角”省略空间或灯光重新计算。
- **道具/载具/图案文字**：锁定轮廓、部件数量、连接、尺度、功能和文字母版；生成后的逐字符/逐图形检查不能被 Prompt 承诺替代。
- **生物/怪物**：锁定形态定义、肢体/器官数量、连接、关节、承重、固定不对称与目标静止姿态；不把运动过程或多个转化阶段混成正式图片。
- **VFX**：标明视觉母版、状态变体或接触参考中的唯一一种，只展示一个代表阶段；锁定来源、材料层级、尺度、自发光/受光、接触和背景可分离性，不写镜头运动与完整时间轴。

## 交付前检查

逐项确认：

- 上游卡、父资产、附加资产和任务版本均可唯一定位且状态合法
- 正文只有一个生成任务，参考图职责互不冲突
- 所有必须继承项在正文可执行表达，所有变化都落在允许范围内
- 目标画面能供责任资产 Skill 按其检查清单验收
- 没有用“8K、电影级、真实、保持一致、解剖正确”等空泛词替代具体事实
- 平台设置只填写当前界面实际支持的选择，不虚构尺寸、参考数量或控制参数
- 管理字段、Profile 名、内部路径、登记指令和失败记录要求没有进入 Prompt 正文

交付后用一行回显：

`图片PromptID@版本｜Prompt：待人工检查｜生成结果：未生成或未回报｜候选验收：待责任资产Skill复核`

这只是当前生产对话的轻量检查点，不写项目记录表。

## 结果回流与返工分流

用户回传图片、可唯一定位的候选或调整方向后，先比较“交付卡目标—Prompt 正文—可见结果”，再分四类：

1. **漏译、歧义、优先级或参考映射错误**：本 Skill 完整重写 Prompt，递增版本。
2. **上游设计需要改变**：返回唯一责任资产 Skill 更新生产卡；收到新版本后再重写 Prompt。
3. **长期风格、材质或灯光规则需要改变**：返回相应专业 Skill，经项目版本流程生效后再重写 Prompt。
4. **Prompt 正确但模型随机未执行**：把可见偏差和用户调整方向交责任资产 Skill。用户选择原样再生成时保持 Prompt 版本；用户要求强化或改写表达时建立下一 Prompt 版本。

责任资产 Skill 按自身检查层级给出候选结论。本 Skill 不把“看起来不错”改写成批准，不擅自定义失败原因。失败图、待调整图和无法唯一定位的图不登记；只有用户明确要求“记录失败原因”“保存这次版本”等，才转 `generation-version-log`。

如果用户在当前生产对话明确说“登记这张”“确认登记”，将该原文、唯一候选、当前图片 Prompt 交付卡和上游生产卡返回责任资产 Skill；由其完成业务复核并决定是否输出登记申请。未收到专用登记对话回执前，不得称候选为可调用资产。

## 输出

- GPT Image 2 图片 Prompt 交付卡及稳定 `图片PromptID@版本`
- 新生成/参考编辑模式、平台设置与参考图用途映射
- 可完整替代上一版的 Prompt 正文
- `PRESERVE EXACTLY / CHANGE / ONLY CHANGE` 与生成后检查清单
- 当前轻量检查点
- 结果回流后的问题归属、下一版本或上游返回节点
- 任务成果索引草案/激活事务结果；不写正式资产登记表
