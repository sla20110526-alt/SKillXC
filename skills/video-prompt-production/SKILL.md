# Seedance 2.0 视频 Prompt 生产

## 前置条件

必须通过 `continuity-readiness-audit`，拥有用户确认的分镜，并已完成逐镜摄影审核及其技术修正写回。只调用正式可调用资产；人物使用单张五视图总览卡。本阶段只读取分镜中的摄影决定和摄影规则卡最小切片，不重新询问或加载完整摄影 Profile。

## 装配顺序

1. 列出当前生成单元实际使用的图片、视频和音频参考及各自唯一用途。
2. 写场景与空间关系，再写摄影机和风格。
3. 明确第一帧已有的人物、位置、前中后景、距离、身体朝向和眼神目标。
4. 按镜头分别写时长、景别对象、机位、视场/焦段、主要运镜、开始状态、动作、表演、对白、受光和稳定结束状态。
5. 身体朝向与眼睛方向分开写；移动方向与银幕方向分开核对。
6. 接触动作写重量、惯性、摩擦、接触点和重心，不用“真实物理”代替。
7. 跨切镜保持脸、发型、服装、伤口、污迹、道具、左右手、光线和空间连续。
8. 声音写说话者、原句、环境声和禁用项；不自动加字幕、音乐或画外音。
9. 删除无关旧上下文、管理语言、不可见细节和互相冲突的质量口号。

## 格式

只使用连续单镜头或镜头组。模板见 [Seedance Prompt结构](references/seedance-prompt-structure.md)。当前平台能力和输入限制应在使用时核对，不把暂时性上限写成永久规则。

## 回流诊断

区分分镜设计错误与模型执行偏差。设计错误退回相应 Skill；设计正确但未执行时精简优先级、减少同时动作或拆生成单元。失败原因仅在用户明确要求时记录。
