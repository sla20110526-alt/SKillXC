# Seedance 2.0 视频 Prompt 生产

## 前置条件

必须通过 `continuity-readiness-audit`，拥有结构校验通过、剪辑修订已写回且逐镜摄影审核完成的当前分镜组快照。只调用正式可调用资产；人物使用单张五视图总览卡。本阶段不另设“分镜批准”步骤，只读取分镜中的摄影决定和摄影规则卡最小切片，不重新询问或加载完整摄影 Profile。

对本生成单元出场的重要角色，核对分镜引用的场戏表演卡和当前有效母档版本。只提取镜头内可见的目标、策略、倾听、眼神、呼吸、重心和动作状态；不复制母档全文，不根据演员外貌、台词或“悲伤/愤怒”等抽象词另造一套表演。

对本生成单元出场的生物/怪物，核对当前可调用生命体版本、形态定义和运动约束集版本。只提取当前镜头所需的支撑、发力、第一动作、关节范围、节律、速度、转向/制动、惯性、环境接触、次级运动和禁止动作；不在 Prompt 内新增肢体、器官、能力或未定义转化阶段。

对有台词、独白或画外发声的角色，核对 `sound-voice-direction` 已交付场戏声音卡；逐个读取当前有效声音身份卡和正式声音资产版本/调用方式，或用户已明确选择的 Seedance 临时镜头内声音。来源为 `未决定` 时不得写正式 Prompt；Prompt 生产不得替用户选择临时声音、不得把身份卡或临时声音伪装为正式声音资产。

按 [分镜、正式 Prompt 与可用镜头的版本状态规则](../production-router-handoff/references/shot-prompt-version-state.md) 核对分镜组 ID/版本、镜头 ID/版本和生成单元 ID。每个生成单元建立稳定的正式 Prompt ID；首次交付为 `v001`。

## 装配顺序

1. 列出当前生成单元实际使用的图片、视频和正式音频参考及各自唯一用途；临时镜头内声音单列为用户决定，不列入正式资产。
2. 写场景与空间关系，再写摄影机和风格。
3. 明确第一帧已有的人物、位置、前中后景、距离、身体朝向和眼神目标。
4. 按镜头分别写时长、景别对象、机位、视场/焦段、主要运镜、开始状态、动作、表演、对白、受光和稳定结束状态。
5. 身体朝向与眼睛方向分开写；移动方向与银幕方向分开核对。
6. 接触动作写重量、惯性、摩擦、接触点和重心；生物动作另写支撑、发力、关节范围、节律和次级运动，不用“真实物理”“动物般”代替。
7. 跨切镜保持脸、发型、服装、伤口、污迹、道具、左右手、光线和空间连续。
8. 声音写说话者、原句、身份短描述、来源、逐场声音表现、环境声和禁用项；正式音频参考如实写平台引用名与调用方式，临时声音明确由本镜头生成且不得自动改变说话者。非说话角色不得动嘴，不自动加字幕、音乐、额外对白或画外音。
9. 删除无关旧上下文、管理语言、不可见细节和互相冲突的质量口号。

## 格式

只使用连续单镜头或镜头组。模板见 [Seedance Prompt结构](references/seedance-prompt-structure.md)。使用 `assets/正式Prompt交付卡模板.md` 标明源分镜版本、Prompt ID/版本和完整正文；当前平台能力和输入限制应在使用时核对，不把暂时性上限写成永久规则。

每次修订必须交付可替代上一版的完整 Prompt，并递增 Prompt 版本。只优化 Prompt 表达而未改设计时不递增镜头版本；需要改变叙事任务、机位、构图、运镜动机、人物动作、资产或时长时先返回责任 Skill，形成新分镜组快照并递增实际改变镜头的版本，再重写 Prompt。生成单元拆分或合并会改变身份：为新生成单元建立新的生成单元 ID 和正式 Prompt ID，不在旧 ID 下只递增版本。

## 轻量检查点

- 新 Prompt 交付后，当前对话状态为 `待人工检查`。
- 用户明确说“这组 Prompt 通过”“Prompt 没问题，我去生成”时，只记当前对话检查点 `已放行生成`；这同时确认本 Prompt 引用的分镜版本为本次生成依据，不代表视频可用。
- 用户明确说“这个镜头可用”“成片可用”时，只记可唯一定位生成单元的结果状态 `可用`，并默认当前结果被项目采用；用户明确说只是备选时不作采用结论。用户结论已经足够，不要求上传视频。
- 用户说“上一组通过”但无法从紧邻上下文区分 Prompt 与生成结果时，先问清；“继续”“不错”“可以”不单独改变正式状态。
- 生产对话不写项目进度表。每次确认后用一行复述 `PromptID@版本｜Prompt状态｜生成结果状态`，随即继续下一组或返修，不启动登记流程。

用户说“导出本对话进度包”时，使用 `../generation-version-log/assets/镜头生产进度同步包模板.md` 汇总当前对话可确认的最新状态，但不写项目文件。用户说“同步本对话进度”或“登记本组进度”时，再附上 `../generation-version-log/assets/镜头进度记录对话激活指令模板.md`；正式写表由独立记录对话完成。

## 回流诊断

区分分镜设计错误与模型执行偏差。设计错误退回相应 Skill；设计正确但未执行时精简优先级、减少同时动作或拆生成单元。待返修状态可以保留，但失败原因、完整诊断和参考证据仅在用户明确要求时记录。

本阶段是外部人工生成节点：默认只交付供用户手工复制到 Seedance 的 Prompt，不调用提交任务、查询进度或下载视频接口。
