# Seedance 2.0 镜头组 Prompt 正文模板

> 只复制本模板填写后的正文到 Seedance；所有 ID、版本、路径、状态和平台核对记录保留在交付卡与参考映射表。

## 参考绑定与跨镜基准

- `【平台引用名】`：只用于【唯一用途】；允许继承【可见属性】；禁止继承【身份/场景/动作/光线等不适用属性】。

风格执行基准：【已批准且可观察的真人写实、材质、色彩与成像结果】。
跨镜必须保持：【人物身份、服装/妆造/伤势、道具/左右手、空间锚点、轴线/方向、VFX阶段/残留、声音桥、世界光源逻辑】。

## 生成单元

总时长【秒】，共【镜头数】个镜头；逐镜时长之和必须等于总时长。切法与顺序按下列镜头执行，不合并成一镜到底，也不增加镜头。

## 镜头【序号】｜【时长】秒

切入与上一镜接点：【首镜写生成单元进入状态；后续写 CUT 时机、动作/声音接点和相邻状态】。

空间与摄影：【场景锚点、人物/物体关系、景别对象、摄影机位置、高度/角度、视场/透视、构图、运镜、触发和停止】。

第一帧：【人物、位置、前中后景、距离、身体朝向、视线、姿态、道具接触、VFX/声音/光线和摄影机状态】。

动作与表演：【按触发—准备—执行—反应—停顿；身体方向、眼神方向、移动方向与摄影机响应分写】。

物理接触：【不适用 / 接触部位、力量、重量、惯性、摩擦、重心、结果与恢复】。

台词与声音：【说话者、锁定原句、口型、声音来源、逐场表现、环境/动作/VFX接点、静默和禁项】。

光影执行：【来源、人物受光、阴影/反射、变化触发、VFX环境承接与曝光护栏】。

稳定结束状态：【最终姿态、视线、位置、道具、VFX残留、声音尾部、光线与摄影机状态】。

切出：【下一 CUT 的可定位时机与理由；末镜写生成单元稳定结束】。

> 按同一结构重复每个镜头；不得用“同上”省略后续镜头。
