# Seedance 2.0 Prompt 结构

正式 Prompt ID、版本、源分镜版本和状态只写在正式 Prompt 交付卡中，不复制进 Seedance Prompt 正文；正文不得包含版本管理或工作流语言。

## 资产参考

逐行列出当前生成单元实际使用的正式人物总览卡、场景视图、道具、VFX 和正式声音资产。正式 VFX 写 `VFX资产ID@版本 + 平台引用名 + 唯一用途`，并在交付卡列出对应定义、时序与接触集版本；一次性普通效果不加入正式资产清单，只写已批准的单镜执行条款。正式声音资产写 `声音资产ID@版本 + 平台引用名 + 调用方式 + 唯一用途`。用户选择的 Seedance 临时镜头内声音另列“临时声音决定”，不加入正式资产清单；没有发声内容时写“本单元无需独立声音资产”。

## 画面执行基准

写入风格锁定阶段形成的短执行描述，不写 Profile 名字堆叠或“读取某文件”。

## 单镜头

`连续单镜头，总时长。场景与第一帧空间锁定。景别对象、摄影机位置、视场和主要运镜。按时间顺序写动作、表演、VFX可见阶段/接触/受光、原台词、声音和稳定结束状态。`

## 镜头组

写总时长、镜头数和切法。每镜独立写时长、场景视图、第一帧、摄影机、动作、表演、台词、光线、声音和结束状态。时长之和必须等于总时长。

## 末尾约束

只保留当前镜头高风险且容易漂移的约束。禁止字幕、音乐或额外对白时明确写出；不要重复几十条泛化否定词。

## 声音正文最小结构

`说话者与原句。当前声音身份短描述。声音来源：正式声音资产及真实调用方式 / 用户确认由本镜头临时生成。逐场音量、停顿、呼吸、句尾与空间距离。环境底声、动作声接点、静默或声音桥。非说话者不动嘴；禁止额外对白、字幕、音乐和未指定画外音。`
