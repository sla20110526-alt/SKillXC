# Seedance 2.0 Prompt 结构

## 资产参考

逐行列出当前生成单元实际使用的正式人物总览卡、场景视图、道具和声音。说明每项用途，不加入未调用资产。

## 画面执行基准

写入风格锁定阶段形成的短执行描述，不写 Profile 名字堆叠或“读取某文件”。

## 单镜头

`连续单镜头，总时长。场景与第一帧空间锁定。景别对象、摄影机位置、视场和主要运镜。按时间顺序写动作、表演、原台词、受光、声音和稳定结束状态。`

## 镜头组

写总时长、镜头数和切法。每镜独立写时长、场景视图、第一帧、摄影机、动作、表演、台词、光线、声音和结束状态。时长之和必须等于总时长。

## 末尾约束

只保留当前镜头高风险且容易漂移的约束。禁止字幕、音乐或额外对白时明确写出；不要重复几十条泛化否定词。
