# Seedance 2.0 Prompt 正文结构

本文件只说明正文结构。版本、上游引用、平台能力和状态写在正式 Prompt 交付卡；媒体来源、顺序和唯一用途写在 `VRM` 参考映射表。正文不得复制内部 ID、版本、路径、Profile 名、登记指令或工作流语言。

## 共同结构

1. `参考绑定`：只使用平台引用名，并逐项说明唯一用途与禁止继承项。
2. `风格执行基准`：用短句描述可观察画面结果，不堆质量口号。
3. `空间与摄影`：场景锚点、人物/物体关系、景别对象、摄影机、构图、透视和已经锁定的运镜。
4. `第一帧`：画面开始时已经存在的全部可见状态。
5. `动作与表演`：按触发—执行—反应—停顿的时间顺序。
6. `物理接触`：接触点、重量、惯性、摩擦、重心与结果；不适用时省略。
7. `台词与声音`：原句、说话者、声音来源、口型、环境/动作声、静默和禁项。
8. `光影`：来源、人物受光、阴影/反射、变化触发和曝光保护。
9. `稳定结束状态`：可保持并能承接下一镜头的最终状态。
10. `最小高风险禁项`：只写本单元最容易漂移的具体禁项。

## 单镜头

使用 [单镜头Prompt正文模板](../assets/单镜头Prompt正文模板.md)。必须明确“连续单镜头”、总时长、一个主摄影运动链和稳定结束状态。不得在中途暗含第二机位、跳切或未设计的镜头切换。

## 镜头组

使用 [镜头组Prompt正文模板](../assets/镜头组Prompt正文模板.md)。必须写总时长、镜头数、逐镜时长和 `CUT` 边界；逐镜时长之和等于总时长。组内每镜分别保留空间与摄影—第一帧—动作/表演—接触—声音—光影—结束状态，不能只在第一镜写完整、后续写“同上”。

## 参考与声音

- 人物只使用一张与当前服装/状态匹配的五视图总览卡，不叠加脸母图或五张独立图。
- 正式 VFX、声音或其他媒体只有在 `VRM` 写明来源、处理方式和唯一用途后才能引用。
- Seedance 临时镜头内声音写为用户已确认的生成决定，不冒充正式音频参考。
- 非说话者不动嘴；禁止项只有上游明确要求时才写，不自动禁止或添加字幕、音乐、旁白和额外对白。

## 清理

删除“读取文件”“保持所有一致”“登记这张”“最终版”等管理语言；删除无法观察的心理解释；删除互相重复的“8K、IMAX、电影感、超真实、非3D”等口号。任何删减都不得丢失上游已经锁定的具体空间、摄影、表演、声音、灯光、VFX或连续性决定。
