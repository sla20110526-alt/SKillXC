# VFX 视觉与时序规则

## 最小视觉字段

- 剧情功能和可识别名称
- 触发者、来源位置、初始方向和影响半径
- 现实/艺术化/超自然规则及顾问依据
- 材料类型、主体轮廓、内部层级、颗粒/碎屑尺度
- 密度、透明度、边缘、颜色和发光区域
- 与人物、对象、地面、空气和环境光的接触
- 代表阶段及直接参考图用途
- 跨镜必须保持和允许随强度变化的项目

## 时序卡

| 阶段 | 必须回答 |
|---|---|
| 触发 | 谁/什么触发，起点、延迟和第一可见信号 |
| 形成 | 形态如何建立，初始速度、尺度和方向 |
| 发展 | 传播路径、湍流/轨迹、材料交换和环境接触 |
| 峰值 | 最大尺度、亮度、密度、破坏或遮挡范围 |
| 衰减 | 如何失能、冷却、稀释、落下或离开画面 |
| 残留 | 烟、灰、湿痕、焦痕、碎屑、余光或无残留 |

每个阶段写持续时间范围，不能只用“慢慢”“快速”。若镜头时长不足以完成全部阶段，交剪辑/镜头设计决定拆镜或选择可见阶段，不在 Prompt 中压缩成瞬间跳变。

## 发光与曝光

- 自发光：写清发光体、颜色、相对亮度、照明范围、反射和曝光保护对象。
- 非发光：只接受环境光，不产生无来源轮廓光。
- 强光峰值：允许何处过曝、持续多久、结束后环境曝光如何恢复。
- 与已登记灯光状态冲突时返回灯光指导，不以特效静帧重写场景主光。

## 资产与镜头边界

视觉母版回答“它长什么样”；时序卡回答“它如何发生”；正式镜头 Prompt 回答“本镜看到哪个阶段、从哪个机位、与哪些资产如何接触”。三者不得相互替代。
