# VFX 视觉、物理与时序规则

## 身份事实门

先核对剧情功能、可识别名称、触发者、来源、介质、初始尺度、影响范围、现实/艺术化/超自然规则以及结果。缺少会改变因果或安全的事实时标记未知，不用类型片惯例补写。

## 材料与运动语言

- 烟雾/体积：浮力、风场、涡流尺度、扩散、密度、遮挡与消散。
- 尘土/碎屑：粒径分布、喷发方向、重力、弹跳、碰撞、沉积与残留。
- 液体/血液：黏度、表面张力、流量、重力、飞溅尺度、润湿与汇流。
- 火焰/高温：燃料与氧化来源、附着/传播、热羽流、烟、余烬和熄灭条件。
- 光束/等离子/超自然能量：来源截面、内部层级、边缘、传播、能量衰减、自发光和规则例外。
- 破坏：受力起点、裂纹/断裂传播、碎片尺度、动量、二次碰撞、尘雾和稳定结果。

现实类效果遵守质量、动量、浮力、重力和材料响应；超自然效果可例外，但必须写明例外范围与代价，不能只在不方便时关闭物理。

## 六阶段时序

1. **触发**：触发者、起点、延迟、第一可见/可听信号。
2. **形成**：形态如何建立，初始速度、尺度、方向和材料来源。
3. **发展/传播**：路径、加减速、湍流、材料交换、接触和范围增长。
4. **峰值**：最大尺度、密度、亮度、遮挡、冲击或破坏范围。
5. **衰减**：失能、冷却、稀释、下落、撤离或熄灭条件。
6. **残留**：烟、灰、湿痕、焦痕、碎屑、余光，或明确无残留及归零条件。

每阶段写进入条件、持续时间范围和结束条件。阶段可短到不可单独辨认，但不得无理由从触发跳到峰值或从峰值瞬间清空。正式 Prompt 只提取当前镜头可见阶段及相邻转折。

## 发光、受光与曝光

- 自发光：定义发光体、颜色来源、相对亮度层级、照明半径、随阶段变化、反射和散射。
- 非发光：只接受场景光，不产生无来源轮廓光、彩色溢光或曝光变化。
- 峰值强光：写允许过曝区域、保护对象、持续范围和环境曝光恢复逻辑。
- VFX 定义产生什么光；灯光指导决定场景如何接收并保持主光逻辑；摄影审核检查曝光与可读性。

## 环境接触因果

每个接触项按顺序写：`来源 → 接触区域/时刻 → 作用方式 → 对象即时反应 → 次级运动 → 残留/恢复`。

接触方式可包括照明、遮挡、投影、反射、散射、冲击、推移、包覆、附着、润湿、加热、燃烧、侵蚀、破坏、沉积和无直接接触。接触对象未登记或空间位置不清时不得制作正式接触参考；返回对象/场景/生命体责任 Skill。

## 版本影响

视觉轮廓、材料层级、颜色来源、自发光身份或核心物理规则改变时升级 VFX 定义并复核所有正式图片、时序/接触集、分镜和 Prompt。阶段持续、传播或残留实质改变时升级时序集；接触区域、作用或对象反应改变时升级接触集。只修正错字、路径或不改变语义的格式不升级。
