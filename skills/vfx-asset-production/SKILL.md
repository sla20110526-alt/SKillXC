# VFX 视觉资产生产

首次进入先判断需求是否满足独立 VFX 资产门。不满足时不启用本 Skill，返回场戏/镜头设计或 `video-prompt-production` 处理单镜动态描述；满足时说明准备建立的可复用视觉身份和交付，再询问用户是否确认使用。图片模型固定为 GPT Image 2；Seedance 2.0 负责镜头内运动，不把一张静帧误当成完整特效模拟。

## 是否建立资产

满足以下任一条件才建立独立 VFX 资产：跨镜反复出现且必须保持同一轮廓/颜色/材料身份；是剧情可识别力量或现象；需要独立审批；多个镜头必须共享明确来源和阶段规则。

普通尘土、火花、呼吸雾、运动模糊、一次性轻微飞溅或只服务单镜的反应，直接写入场戏/VFX短卡和正式镜头 Prompt，不预留或登记独立资产。

## 输入门

- 项目绑定卡、需求槽位、预留正式资产 ID、剧本因果与关联场次
- 当前有效风格、美术、灯光与摄影最小切片
- 触发源、附着对象、场景和生物等正式资产精确版本
- 现实物理、有限艺术化或超自然规则
- 必须继承、允许变化、禁止变化和用户参考
- 流体、火焰、爆炸、破坏或危险现象所需的 VFX/物理顾问结论

无法确定来源、时间阶段、接触对象或是否发光时暂停。详细字段见[VFX视觉与时序规则](references/vfx-visual-temporal.md)。

## 生产模式

1. **视觉身份母版**：建立最清楚的代表阶段、轮廓、内部结构、尺度、颜色和材料/粒子语言。
2. **状态/强度变体**：继承精确母版，只改变已批准的强度、污染、颜色阶段或破坏等级。
3. **接触参考**：只有接触关系需要跨镜复用时，才基于已登记对象/场景版本建立候选；否则在镜头 Prompt 动态组合。
4. **转化/破坏配套**：前后对象状态由对象责任 Skill 生产；VFX Skill 只管理中间现象和环境反应。

## 视觉身份

- 明确来源位置、初始尺度、主要运动轴和影响半径。
- 区分烟雾、尘土、液体、火焰、等离子、碎屑、光束、体积雾等材料行为，不混成通用“能量特效”。
- 定义主体轮廓、内部层级、颗粒尺度、密度、透明度、边缘、湍流/轨迹和衰减方式。
- 发光效果写清自发光区域、亮度层级、颜色、对人物/地面/空气的照明和曝光风险；非发光效果不得凭空照亮环境。
- 写清遮挡、投影、反射、散射、残留、地面痕迹和对头发/服装/植被/碎屑的接触。

## 静帧与时序分工

用于 Seedance 参考的正式图片只锁定一个代表阶段，避免把起始、峰值、消散三种状态同时塞进直接参考图。需要审批多个阶段时可制作“行为分阶段设计板”，但默认只作设计审查，不作为视频模型直接参考，也不与视觉母版共用正式资产身份。

另外输出文字版时序卡：触发 → 形成 → 发展/传播 → 峰值 → 衰减 → 残留。为每阶段写持续时间范围、速度/方向、尺度、亮度、接触和禁止突变。时序卡由任务索引追踪，不作为图片资产登记。

## Prompt 与检查

把确认后的代表阶段、构图用途、参考映射与继承清单交 `image-prompt-production`。复核来源、轮廓、尺度、材质行为、发光、接触、环境反馈和背景可分离性。禁止只写“电影级VFX、粒子丰富、能量流动、真实物理”。

## 登记与返工边界

只有用户对唯一视觉母版或明确状态图说“登记这张”“确认登记”等才输出登记申请。行为设计板、文字时序卡、失败图和仍待修改候选不自动登记。父对象/场景版本变化时只复核兼容性，不改正式状态；失败原因按用户明确要求另行记录。

## 输出

- VFX视觉身份卡与代表阶段图片定义
- 文字版时序与环境接触卡
- GPT Image 2 Prompt 装配输入与生成后检查清单
- 镜头 Prompt 所需的短执行条款
- 用户明确登记后的登记申请，或返工方向
