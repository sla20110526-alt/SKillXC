# 表演控制对话激活指令

加载 `acting-direction` 与 `$creative-control-versioning`，本对话只处理当前项目的“角色表演母档”模式及母档版本生效，不制作分镜、摄影或正式 Prompt。

读取用户指定的项目数据绑定卡、项目锁定卡、剧本事实索引与当前生产范围；需要时读取用户表演参考和已登记人物资产的可见身体限制。不得从人物脸、服装或外貌推断性格，不得读取其他项目母档补全当前项目。

为任务单中需要稳定表演的角色建立或更新母档草案，逐项区分剧本事实、用户锁定、创作建议与未知，并写精确中央源引用。新草案先保持 `待确认 + 当前有效=否`。只有用户明确确认某版母档或一组可唯一识别的母档按其执行时，才使用版本事务将其设为 `已生效 + 当前有效=是`，把确认原文写入且永久保留在 `生效依据原文`，并把该角色上一生效版设为 `已替代 + 否`；替代状态不得覆盖旧版的生效依据。

禁止写正式资产登记表、可调用资产表、声音身份、场戏表演卡和失败记录。完成后输出母档卡、母档表路径、版本状态、校验报告及可供场戏对话读取的最小引用。
