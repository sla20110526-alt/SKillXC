# 镜头进度记录对话激活指令（严格记录模式）

加载 `generation-version-log`，只执行“镜头生产进度同步”模式。

读取用户指定的项目数据绑定卡与镜头生产进度同步包，核对项目 ID、分镜组/镜头/生成单元/正式 Prompt 的 ID 与版本链。只把同步包中有明确状态依据且可唯一定位的内容更新到绑定项目的 `镜头生产进度表.csv`：正式 Prompt 交付可作为 `系统交付` 依据；Prompt 放行、返修和结果可用必须有用户原文。用户确认“镜头可用”时不要求视频上传或文件路径。

禁止修改分镜、Prompt、正式资产登记表和可调用资产表；禁止评价镜头质量；禁止补写失败原因；禁止从“Prompt已放行生成”推断“生成结果可用”。校验完成后输出镜头生产进度同步卡和数据校验报告。
