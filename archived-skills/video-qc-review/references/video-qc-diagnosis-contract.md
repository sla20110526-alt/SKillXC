# 视频 QC 诊断与返工合同

本文件用于选择可观察问题类别、根因层、唯一责任节点与最小复核动作。先描述结果，再对照当前期望版本，不用结果反推模型内部机制。

## 八类可观察问题

| 问题类别 | 可观察项目 | 常用期望依据 |
|---|---|---|
| 人物身份与状态 | 脸、年龄感、发型、体型、服装、妆造、伤势、污迹、左右状态 | 当前正式人物五视图卡、人物状态版本、VRM人物参考行 |
| 表演与口型 | 目标行为、倾听、视线、呼吸、重心、停顿、反应、说话者口型 | 表演母档、场戏表演卡、锁定台词与VPR动作/声音段 |
| 动作与物理接触 | 触发、顺序、接触点、重量、惯性、摩擦、重心、形变、恢复 | 分镜动作、道具/生命体约束、VPR接触段 |
| 构图与运镜 | 景别对象、机位、高度、角度、视场、构图、运动触发/停止、稳定结束 | 当前分镜、逐镜摄影审核写回、VPR空间与摄影段 |
| 空间与光线 | 门窗/家具/地形锚点、距离、光源方向、受光、阴影、反射、曝光 | 空间圣经/锚点、灯光短执行卡、VPR光影段 |
| 连续性 | 轴线、银幕方向、位置、左右手、道具、服装/伤势、VFX阶段、声音桥 | 分镜首尾状态、CUT接点、连续性就绪结论 |
| VFX | 身份、来源、触发、形成、传播、接触、受光、消散、残留 | VFX定义/时序/接触、灯光环境承接、VPR VFX段 |
| 声音 | 说话者、声音身份、原句、口型同步、呼吸、距离、环境/动作声、静默、额外音乐/字幕 | 场戏声音卡、正式或临时声音决定、VPR声音段 |

一个现象跨多个类别时，按实际需要修订的主字段选主类别；不同根因拆成不同问题 ID。

## 证据载体边界

| 证据 | 可以确认 | 不能单独确认 |
|---|---|---|
| 有声完整视频 | 时间、动作、运镜、表演、声音、首尾与跨切 | 未提供的上游版本是否正确 |
| 无声完整视频 | 时间、动作、运镜、表演、首尾与跨切 | 声音、口型所对应的实际音频内容 |
| 单张或多张截图 | 指定帧的身份、构图、空间、光影、静态接触/VFX阶段 | 完整动作、节奏、声音、运镜路径与稳定结束 |
| 用户明确文字反馈 | 用户实际观察和结果结论；可据此做有限路由 | 用户未描述的视觉/听觉细节，或声称AI已直接核验 |

证据定位必须可回到时间点、截图序号或用户原文。`00:03.200–00:04.100`、`截图02`、`用户原文：“右手变成左手”`均可；“中间不对”不足以形成已确认根因。

## 根因判定树

1. **期望本身是否错误或不可执行？** 是：`上游设计错误`；返回该字段唯一写入者。
2. **期望正确且 VPR 是否完整、无歧义地翻译？** 否：`Prompt漏译或冲突`；返回 `video-prompt-production` 建下一 VPR。
3. **VPR正确，VRM来源/顺序/用途/继承/状态/负载是否错误？** 是：`参考映射或负载问题`；返回 `video-prompt-production` 先建下一 VRM，再建下一 VPR。
4. **上游、VPR、VRM和设置均正确，是否只是本次结果偏离？** 可由对照证据支持：`模型随机偏差`；完全相同输入原样重试，不升级版本。
5. 任一步缺少对照材料：`证据不足暂不可判定`；只请求最小缺失证据。

`已确认` 需要结果证据与相应版本对照直接支持；`高概率` 用于最符合当前证据但仍缺一次对照；`待复核` 用于多种原因仍无法排除。不得仅凭“模型经常这样”把随机偏差写成已确认。

## 唯一责任映射

| 需要改变的主字段 | 唯一返回节点 | 最小修订 |
|---|---|---|
| 剧本事实、锁定台词或事件因果 | `script-truth-index` 或剧本授权节点 | 先确认源剧本/授权，不在QC改写 |
| 场戏节拍、潜台词或策略依据 | `dramaturgy-scene-beats` | 建下一节拍成果版本 |
| 人物走位、朝向、视线关系、遮挡或轴线意图 | `directing-blocking` | 建下一调度成果版本 |
| 角色表演母档或场戏表演执行 | `acting-direction` | 更新唯一对应表演成果 |
| 镜头叙事任务、景别、机位、构图或运镜 | `shot-visual-design` | 建下一分镜/镜头版本并重走审核 |
| 时长、切点或生成单元拆分/合并 | `editing-rhythm` | 提出下一ERT/ERC，再由分镜写回和摄影审核 |
| 摄影基线/场戏约束或逐镜摄影技术问题 | `cinematography-direction` | 审核后由分镜写回，不由QC改表 |
| 世界光源、人物受光或VFX环境承接 | `lighting-direction` | 更新对应灯光成果 |
| 台词声音来源、表演、环境/动作声决定 | `sound-voice-direction` | 更新场戏声音成果或让用户决定来源 |
| 人物/场景/道具/生命体/VFX正式身份或状态 | 对应资产生产 Skill | 先生产候选，明确登记后才可调用 |
| VFX本体、时序、接触或残留 | `vfx-asset-production` | 更新VFX定义/执行成果 |
| VPR正文漏译/冲突 | `video-prompt-production` | 下一VPR，VRM不变 |
| VRM参考来源/职责/负载 | `video-prompt-production` | 下一VRM和下一VPR |
| 完全正确输入的偶发执行偏差 | 外部人工生成节点 | 相同输入原样重试，无版本变化 |

如果一个症状既可能是上游也可能是 Prompt，先把根因状态写“待复核”，比较对应上游段与 VPR；不要同时发两张返工任务。

## 项目复盘聚合

项目复盘按问题类别、根因层、责任节点和修订效果统计，只使用可追溯诊断。文字回忆可列入“用户反馈”，不能升级成视觉核验。

可能通用化的规则候选至少要说明：重复对象与次数、跨场景/跨项目适用性、现有 Skill 归属、会阻止哪类失败、可能造成的副作用。项目人物身份、具体场景、单片风格和偶发随机结果默认是项目特有，不自动转成中央 Skill 或新的项目模板 Skill。
