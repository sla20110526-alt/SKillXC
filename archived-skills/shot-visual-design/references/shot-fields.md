# 镜头字段说明

- 每行以 `项目ID` 开始，防止分镜跨项目混用。
- `分镜组ID`、`镜头ID` 和 `生成单元ID` 是稳定身份；`镜头序号` 才表示当前顺序，重新排序不得改镜头 ID。
- 生成单元的成员集合或内部顺序改变时必须建立新的生成单元 ID，并在 `被替代生成单元ID集合` 保存旧身份；成员和内部顺序未变、仅整单元重排时保留 ID。
- 版本递增遵循 [分镜、正式 Prompt 与可用镜头的版本状态规则](../../production-router-handoff/references/shot-prompt-version-state.md)：组内任何变化形成新组快照，只递增实际改变镜头的镜头版本。
- 叙事任务与存在理由先于摄影参数。
- 逐镜字段由 `shot-visual-design` 唯一写入；摄影审核只能通过审核卡提出技术修正，不能直接改 CSV。
- 机位、构图和运镜字段先表达叙事选择；视场、透视、物理距离、景深、曝光和支撑方式必须落在全片摄影规则卡与场戏摄影约束卡的范围内。
- `场景空间依据ID与版本` 必须命中本镜实际使用的一个正式可调用场景母图、场景状态、场景视图或光影状态精确版本；不能只写无版本 ID。若现有空间依据无法支持所选机位，返回补做 SV3 专项视图。
- `调用正式资产` 继续列出本镜全部其他正式资产精确版本及平台引用；不得用这一列掩盖主场景空间依据缺失。
- `生命体形态与运动约束集版本` 在没有生物/怪物时写“不适用”；有生命体时逐个写可调用生命体 `ID@版本`、`形态定义ID@版本` 和 `运动约束集ID@版本`，不得只在调度自由文本中提到动作。
- `VFX正式资产定义时序与接触版本` 没有 VFX 时写“不适用”；跨镜复现时逐个列出可调用的 `VFX资产ID@版本`、`VFX定义ID@版本`、`时序阶段集ID@版本` 和 `环境接触集ID@版本`。一次性普通效果没有正式图片资产时写“不适用”，不得杜撰资产 ID。
- `VFX本镜阶段与执行条款` 必须写本镜可见阶段、触发点、来源和传播路径、接触对象与结果、场内受光、结束/残留状态；一次性普通效果逐字继承 `vfx-asset-production` 已批准的单镜执行条款。没有 VFX 时写“不适用”。
- 景别必须带对象，如“角色A近景”“双人中景”“场景远景”。
- 距离、视场与透视描述可见结果，毫米焦段仅作辅助。
- 运镜包含物理方式、唯一主要意图、触发点和停止点。
- 第一帧与结束状态必须稳定、可见、可供相邻镜头承接。
- 初版分镜草案尚未进入剪辑时，`剪辑关系ID` 写“待剪辑建立”，`剪辑节奏数据集与卡精确引用` 写“待剪辑检查”；切点、接点和相邻状态可以先写镜头设计草案，但不能冒充剪辑成果。
- 剪辑写回后，每行必须保存下一镜头或场末、稳定 `CUT` 关系、切点时机/理由、动作/声音接点、相邻状态结论，以及 `ERT@版本；ERC@版本`。邻接双方变成另一镜头组合时建立新 `CUT` ID。
- `editing-rhythm` 只提出修订；本 Skill 逐项采用或写明不采用理由后建立新分镜组快照，再交逐镜摄影审核。
- 调用资产记录正式资产 ID、版本和平台引用名。
- 摄影技术修正写回后重新执行 Schema 检查；Schema 通过仍不代表用户批准镜头。
