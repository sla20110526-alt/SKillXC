- 当前生成单元 `GU-DEMO-002` 含两个镜头，总时长 7.2 秒；分镜、ERT/ERC写回与逐镜摄影审核均完成。

## 不合格表现

- 同时上传林舟脸母图、人物剧照和五视图卡，声称参考越多越稳定。
- 动作参考同时承担演员身份、服装、场景、摄影和光线。
- 镜头组只写总时长，不写逐镜时长、切点与首尾状态，或逐镜时长之和不等于总时长。
- 把管理 ID、Profile 名、文件路径和“读取某卡”复制进 Prompt 正文。
- 用“8K、IMAX、电影级、超真实、非3D”替代具体空间、表演、接触与光影。
- 平台能力未核对就声称已上传并提交生成，或直接查询、下载视频。
- 同时询问参考处理、是否改镜头、是否更换人物卡和是否记录失败，制造多个决定点。
