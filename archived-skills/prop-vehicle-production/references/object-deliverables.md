# 对象交付、视图与缺口

## 身份事实

最少核对：对象是什么、剧情功能、制造年代与地域、来源/社会层级、制式/民用/自制、使用者、数量、真实尺寸或比例依据。剧本未说明时区分用户锁定、顾问结论、创作建议和待确认。

以下缺口会改变对象身份或功能，必须暂停：对象类别、主要用途、关键尺度、前后左右、部件数量、动作需要的开口/握点/座位、文字原文、安全或历史约束。材质细节和非关键装饰可在美术短卡允许范围内提出候选，但不能写成剧本事实。

## 对象定义与锚点

为同一对象身份建立稳定 `对象定义ID@版本`。每个锚点记录：

- 所在部件与类别：主体轮廓、结构连接、握持、支撑、操作、开合、装配、乘坐、进出、安全、图案区域、尺度参照或其他
- 局部位置、朝向、尺寸/容差、功能状态和可见状态
- 接触对象类别、承载/受力和允许运动
- 事实来源与锁定级别：可见锁定、关系锁定、推断待确认、未知禁止补写

锚点位置使用对象自身前/后/左/右/上/下，不随图片屏幕左右改变。对象定义更新时保留旧来源，并列出受影响的状态、表面应用、装配、人物/生物组合和载具舱内。

## 交付形态选择

### 单主视图卡

适用于简单道具。主对象应占主要画面，使用可读结构的 3/4 角度；只加入尺度参照和一至两个真正必要的细节。参照物不得遮挡对象，也不能被误识别为对象固定部件。

### 单张对象总览卡

适用于复杂机械、武器和载具。最大面板放 3/4 主视图；辅助面板只补主视图无法说明的侧/后方向、开口、底盘、控制或接口。每个面板保持同一对象、状态、图案、部件数量和展示光线。

总览卡不是广告海报：避免速度模糊、夸张透视、环境遮挡、人物表演和戏剧性 VFX。若缩略图使身份细节不可判断，优化面板数量和占比，不无限增加小图。

### 图案文字母版

正视、清洁、无透视、无曲面变形、无材质磨损。若内容同时有标志图形和文字，分别定义图形结构与逐字文本；不要先贴在对象上再反向猜母版。

## 状态与功能检查

状态变体必须回答：变化发生在哪个锚点、程度/阶段、是否改变功能、相邻部件如何受影响、未变化部件如何保持。开/关、锁定/解锁、空/满载等功能状态不能只靠气氛描述。

复杂功能机构若无法从单张静态卡表达，定义一个稳定最终状态而不是把动作过程叠在同图。动作时序交镜头 Prompt；跨镜需要的起止状态分别建立对象状态资产。

## 跨类别边界

- 固定穿戴物若只是服装轮廓的一部分，由人物 Skill 管理；需要独立特写、交互、复用或状态变化时拆为道具。
- 人物/生物持握、穿戴、骑乘或操作图由主体责任 Skill 生产；本 Skill 提供对象正式版本和锚点。
- 载具外观与机械身份属于本 Skill；可拍摄舱内属于场景空间 Skill，外观资产不等于完整内舱。
- 纯机械装置属于本 Skill；生物机械混合体先由世界资产二级路由拆分。
- 爆炸、烟尘、流体和能量时序属于 VFX；过程后的物体结构状态属于本 Skill。
